## Model, constraints and LQR terminal ingredients {#ingredients}

The state $x = (p, v)$ is position and velocity sampled with period 1 under a piecewise-constant acceleration $u$ (chapter [[a01]]); constraints and stage cost are the canonical ones. The MPC problem at the current state is

$$J_N^\star(x) = \min_{u_0, \ldots, u_{N-1}}\ \sum_{k=0}^{N-1} q(x_k, u_k) + V_f(x_N) \quad \text{s.t.} \quad x_0 = x,\ x_{k+1} = Ax_k + Bu_k,\ x_k \in \mathcal X\ (k = 1, \ldots, N),\ u_k \in \mathcal U,\ x_N \in \mathcal X_f,$$
%narrow \begin{aligned} J_N^\star(x) = \min_{u_0, \ldots, u_{N-1}}\ & \textstyle\sum_{k=0}^{N-1} q(x_k, u_k) + V_f(x_N) \\ \text{s.t.}\quad & x_0 = x,\ x_{k+1} = Ax_k + Bu_k, \\ & x_k \in \mathcal X,\ u_k \in \mathcal U,\ x_N \in \mathcal X_f, \end{aligned}

and $\mathcal X_N$ is the set of states where it is feasible. With a local controller $u = -Kx$, chapter [[a11]] requires three things of the terminal ingredients:

1. $\mathcal X_f \subseteq \mathcal X$ and $-Kx \in \mathcal U$ for all $x \in \mathcal X_f$.
2. $(A - BK)x \in \mathcal X_f$ for all $x \in \mathcal X_f$: positive invariance.
3. $V_f((A - BK)x) - V_f(x) \le -q(x, -Kx)$ for all $x \in \mathcal X_f$: the terminal decrease.

The LQR provides all three. With $P$ the stabilising solution of the DARE and $K = (R + B^\top PB)^{-1}B^\top PA$ (chapter [[a07]]), the terminal cost $V_f = x^\top Px$ satisfies condition 3 with equality for every $x$, because the DARE is equivalent to $A_K^\top PA_K - P = -(Q + K^\top RK)$ with $A_K = A - BK$. For conditions 1 and 2 take $\mathcal X_f = \mathcal O_\infty$, the maximal positively invariant set of $x^+ = A_Kx$ inside $\mathcal X_K = \{x \in \mathcal X : -Kx \in \mathcal U\}$, from chapter [[a10]]'s recursion $\mathcal O_0 = \mathcal X_K$, $\mathcal O_{i+1} = \mathcal X_K \cap \{x : A_Kx \in \mathcal O_i\}$ until it stops. Conditions 1 and 2 at the vertices imply them on all of $\mathcal X_f$, since the set is convex and the maps linear; condition 3 is an identity in $x$.

::: define What does the capstone check?
**In plain words:** that every guarantee the concept chapters proved holds on the same system when the computer runs it, and that where the guarantee is absent, the failure is visible.

**More precisely:** the three terminal conditions at the vertices of $\mathcal X_f$; recursive feasibility and the decrease $J_N^\star(x^+) - J_N^\star(x) \le -q(x, u)$ along the closed loop from every feasible grid state, with feasibility certified by an independent linear program; the equality $J_N^\star = V_f$ on $\mathcal X_f$; the same loops without terminal ingredients; and Learning MPC's non-increasing iteration cost from a poor first trajectory.

- Guarantee :: A statement proved for every state of a stated set under stated assumptions.
- Observation :: A statement that held for the cases that were simulated.
- Certificate :: An independent computation that decides a claim, such as the feasibility LP.
:::

## Feasible sets of MPC with terminal ingredients {#feasible}

The feasible set of the MPC problem is the $N$-step controllable set to $\mathcal X_f$ (chapter [[a09]]):

$$\mathcal K_0 = \mathcal X_f, \qquad \mathcal K_{i+1} = \mathcal X \cap \operatorname{Pre}(\mathcal K_i), \qquad \operatorname{Pre}(\mathcal S) = \{x : \exists u \in \mathcal U,\ Ax + Bu \in \mathcal S\}, \qquad \mathcal X_N = \mathcal K_N.$$
%narrow \begin{aligned} \mathcal K_0 &= \mathcal X_f, \qquad \mathcal K_{i+1} = \mathcal X \cap \operatorname{Pre}(\mathcal K_i), \\ \operatorname{Pre}(\mathcal S) &= \{x : \exists u \in \mathcal U,\ Ax + Bu \in \mathcal S\}, \qquad \mathcal X_N = \mathcal K_N. \end{aligned}

Because $\mathcal X_f$ is control invariant, $\mathcal X_f \subseteq \operatorname{Pre}(\mathcal X_f)$, and induction gives the nested sequence $\mathcal X_f = \mathcal K_0 \subseteq \mathcal K_1 \subseteq \cdots \subseteq \mathcal C_\infty$. Each $\mathcal K_i$ is control invariant as well: from $x \in \mathcal K_i$ some admissible input reaches $\mathcal K_{i-1} \subseteq \mathcal K_i$. This set-level statement is recursive feasibility; exercise B.3 proves it for input sequences. The areas are 7.31, 19.35, 27.62, 34.34, 38.07 and 39.25 for $N = 0, \ldots, 5$: all of $\mathcal C_\infty$ from $N = 5$ on.

## Recursive feasibility and stability on a grid {#certificate}

::: callout
**What the theory promises.** For every initial state in $\mathcal X_N$ (chapter [[a11]]; exercises B.3 and B.4): the MPC problem remains feasible at every step; the value decreases, $J_N^\star(x^+) - J_N^\star(x) \le -q(x, \kappa_N(x))$ with $\kappa_N(x) = u_0^\star(x)$ the MPC law; and $J_N^\star(x) \ge \lambda_{\min}(Q)\|x\|^2$ everywhere while $J_N^\star(x) \le V_f(x) \le \lambda_{\max}(P)\|x\|^2$ on $\mathcal X_f$. These are the three Lyapunov conditions, so the origin is exponentially stable with region of attraction $\mathcal X_N$. The LQR ingredients add one fact: from $x \in \mathcal X_f$ the LQR plan is admissible and optimal, because $P$ is a fixed point of the Riccati recursion, hence $J_N^\star = V_f$ and $\kappa_N = -Kx$ on $\mathcal X_f$: inside the terminal set, the MPC is the LQR.
:::

**What is checked.** Each point of a grid with spacing 0.5 over $\mathcal X$, 221 states, that is feasible for $N \in \{2, 3, 5\}$ starts a 40-step closed loop. The demo at the top of the page records feasibility, the decrease residual $J_N^\star(x^+) - J_N^\star(x) + q(x, u)$ (theory: at most zero) and the entry into $\mathcal X_f$, for any horizon from 1 to 6 and for either design.

::: table num
| $N$ | feasible starts | lost feasibility | max decrease residual | max steps to $\mathcal X_f$ | QPs solved |
|---|---|---|---|---|---|
| 2 | 117 | 0 | $2.5 \times 10^{-14}$ | 3 | 985 |
| 3 | 147 | 0 | $1.1 \times 10^{-14}$ | 4 | 1299 |
| 5 | 177 | 0 | $1.9 \times 10^{-13}$ | 6 | 1659 |
:::

**Reading the table.** For $N = 2, 3, 5$ the grid has 117, 147 and 177 feasible starts (for $N = 5$, every grid state of $\mathcal C_\infty$). Every closed loop stayed feasible and entered $\mathcal X_f$ within 3, 4 and 6 steps, after which the value decays with the slope of $\rho(A - BK)^{2t}$, $\rho = 0.331$. Each loop stops once $\|x\| \le 10^{-3}$, so the three horizons solve 3943 closed-loop QPs in all, and the largest decrease residual over every one of them is $2 \times 10^{-13}$, round-off. On 200 random states of $\mathcal X_f$, $J_3^\star$ matches $V_f$ and the first input matches $-Kx$ to $10^{-14}$: the upper bound holds with equality.

**An independent certificate.** A solver's failure flag is not an infeasibility certificate, and its success flag is only as good as its tolerances. The grid therefore decides feasibility with a linear program that shares no code with the QP solver: the smallest $s \ge 0$ such that some input sequence satisfies all constraints relaxed by $s$ (chapter [[a04]]'s `feasibility_margin`). $s = 0$ certifies feasibility, $s > 0$ infeasibility, and the QP is solved only where the LP says there is something to solve. One grid state shows why this matters: $x = (4, 0.5)$, a vertex of $\mathcal C_\infty$ reached from $(1, 2.5)$ with $N = 5$. The position is at its bound with the velocity pointing outward, so $p_1 = 4.5 + 0.5u_0 \le 4$ forces $u_0 = -1$ and the feasible input sequences lie in a hyperplane: a degenerate QP on which an earlier version of the course's solver declared the constraints incompatible. The LP certifies the margin $s = 0$, and the interior-point solver with its active-set polish now returns the plan; the page's solver handles the same vertex.

## Removing the terminal ingredients {#plain}

The textbook variant drops both ingredients, $V_f = 0$ and no terminal set. Its feasible set is $\mathcal K_N(\mathcal X)$, the states that can be kept in $\mathcal X$ for $N$ steps (the recursion of Part 2 started from $\mathcal K_0 = \mathcal X$). This sequence shrinks towards $\mathcal C_\infty$, and for short horizons it contains doomed states: the QP is feasible now, yet every admissible input sequence leaves $\mathcal X$ eventually. None of the proofs of Part 3 applies. Costs are compared with $J_\infty^\star(x_0)$, sandwiched between $J_{12}^\star$ of the terminal design, an upper bound because its plan followed by the LQR is admissible, and $J_{30}^0$ of the plain problem, a lower bound because it drops the tail; the two differ by at most $10^{-9}$ on the grid.

**The grid.** $N = 1$ fails badly: $u_0 = 0$ minimises $q(x_0, u_0)$ whenever $Ax \in \mathcal X$, so the controller coasts until a bound forces it to brake, then brakes as little as possible; states $(p, 0)$ are equilibria, 76 feasible starts never converge, and from 100 of the 177 starts in $\mathcal C_\infty$ it coasts into a state where one braking step is not enough, as from $(-1, 2)$ to $(3, 2)$, where $p_1 = 5 + 0.5u \le 4$ would need $u \le -2$; all 14 doomed starts fail too. $N = 2$ accepts the two doomed grid starts $(0, \pm 3)$, which lose feasibility; every start in $\mathcal C_\infty$ converges, but at up to $2.15\, J_\infty^\star$, and 24 starts pay more than 20 percent extra; from $x_S = (-3.5, 2.5)$ the controller keeps its speed too long, overshoots to $p = 2$ and spirals back, at $1.69\, J_\infty^\star$, where the terminal design with the same $N$ has a worst ratio of 1.0010. From $N = 3$ on nothing visibly goes wrong: $\mathcal K_3(\mathcal X) = \mathcal C_\infty$, and the worst costs are 1.0945, 1.0032 and 1.0000 times $J_\infty^\star$ for $N = 3, 4, 5$.

**What is lost is the certificate.** With $V_f = 0$ the principle of optimality (chapter [[a14]]) gives $J_N^0(x) = q(x, u_0^\star) + J_{N-1}^0(x^+)$, hence

$$J_N^0(x^+) - J_N^0(x) + q(x, u_0^\star) = J_N^0(x^+) - J_{N-1}^0(x^+) \ \ge\ 0,$$

because with a zero terminal cost a longer horizon can only add cost. The decrease inequality of Part 3 holds with the wrong sign: it fails at all 2586 ($N = 2$) and 1548 ($N = 3$) steps away from the origin, and the value even increases at 118 and 42 of them. Proofs for MPC without terminal ingredients exist, but they need a long enough horizon and controllability assumptions (Part 8). The terminal ingredients give the guarantee at every horizon.

## Learning MPC from a poor first trajectory {#lmpc}

Learning MPC (chapters [[a12]] and [[a13]], lab [[b02]]) replaces the designed terminal ingredients by data. The states of every trajectory that reached the target become rows of a matrix $S$, their realised costs-to-go a vector $\mathbf J$, and iteration $j$ solves

$$\min_{u_0, \ldots, u_{N-1},\, \lambda}\ \sum_{k=0}^{N-1} q(x_k, u_k) + \mathbf J^\top\lambda \quad \text{s.t.} \quad x_0 = x,\ x_{k+1} = Ax_k + Bu_k,\ x_k \in \mathcal X,\ u_k \in \mathcal U,\ x_N = S^\top\lambda,\ \mathbf 1^\top\lambda = 1,\ \lambda \ge 0.$$
%narrow \begin{aligned} \min_{\{u_k\},\, \lambda}\ & \textstyle\sum_{k=0}^{N-1} q(x_k, u_k) + \mathbf J^\top\lambda \\ \text{s.t.}\quad & x_0 = x,\ x_{k+1} = Ax_k + Bu_k,\ x_k \in \mathcal X,\ u_k \in \mathcal U, \\ & x_N = S^\top\lambda,\ \mathbf 1^\top\lambda = 1,\ \lambda \ge 0. \end{aligned}

The terminal set is the convex safe set $CS^j$, the hull of the stored states, and the terminal cost the barycentric value $V_c^j$ (exercises B.5 and B.6). For linear dynamics, convex constraints and a convex stage cost, chapter [[a13]] shows that every iteration is recursively feasible and converges to the target; that $J^{j+1}(x_S) \le J^j(x_S)$, because the previous trajectory remains a feasible candidate; and, since each iteration is admissible, $J^j(x_S) \ge J_\infty^\star(x_S)$. The costs therefore converge, but convergence to $J_\infty^\star$ is not among the guarantees.

**Setup.** $x_S = (-3.5, 2.5)$; the first trajectory is the plain $N = 2$ closed loop of Part 4, feasible but at $1.69\, J_\infty^\star$. Stored trajectories must end exactly at the target, so each run stops once $\|x\| \le 10^{-3}$ and is completed by the two deadbeat inputs $[u_0; u_1] = -[AB\ \ B]^{-1}A^2x$. LMPC then runs 10 iterations for each $N \in \{2, 3, 4\}$ with all stored data.

**Reading the run.** The first trajectory costs 28.087, that is $1.69\, J_\infty^\star(x_S)$ with $J_\infty^\star(x_S) = 16.636$. For every horizon one iteration removes almost all of the excess, and no cost increases afterwards, as guaranteed: the largest increase is at solver tolerance. Then the horizons part ways. With $N = 4$ the gap keeps falling, to $4 \times 10^{-10}$, and the trajectory joins the optimal one; with $N = 3$ and $N = 2$ it stalls after the first iteration, at $1.26 \times 10^{-3}$ and $2.96 \times 10^{-3}$. A brute-force grid search over $(u_0, u_1)$, refined three times with $V_c$ evaluated by its LP at every point, confirms that the plateau is not a solver artefact: with the data of iteration 10, the best $N = 2$ plan at $x_S$ costs $16.68548$, the stored trajectory's $J^{10} = 16.68547$ to the search's resolution. The guarantees say nothing about the limit; chapter [[a13]] already warned that feasibility alone gives no optimality guarantee. Even so, the $N = 2$ limit is only 0.30 percent above the optimum, against 69 percent for the trajectory that produced the first data. Lab [[b02]] runs the same kind of experiment at length, with a different seed and horizon, and watches the safe set and the stored values evolve.

## Derivations to reproduce {#derivations}

Each exercise is a derivation that Parts 1 to 5 relied on. Work it out before opening the hint, and the hint before the answer.

::::: exercises
:::: exercise B.1, the condensed QP
Eliminate the states and write the MPC problem as $\min_U \tfrac12 U^\top HU + f^\top U + c$ subject to $GU \le w$. Show that $H \succ 0$ and say which quantities depend on the current state.
::: hint
Substitute $\mathbf x = S_x x_0 + S_u U$ (chapter [[a02]]) into the cost and into every constraint row; the terminal rows use the last block rows of $S_x$ and $S_u$.
:::
::: answer
Stack $\mathbf x = (x_1, \ldots, x_N)$ and $U = (u_0, \ldots, u_{N-1})$; the dynamics give $\mathbf x = S_x x_0 + S_u U$ with the prediction matrices of chapter [[a02]]. With $\bar Q = \operatorname{blkdiag}(Q, \ldots, Q, P)$ and $\bar R = \operatorname{blkdiag}(R, \ldots, R)$ the cost is $x_0^\top Qx_0 + \mathbf x^\top\bar Q\mathbf x + U^\top\bar RU$, and substitution gives $H = 2(S_u^\top\bar QS_u + \bar R)$, $f = 2S_u^\top\bar QS_xx_0$, $c = x_0^\top Qx_0 + x_0^\top S_x^\top\bar QS_xx_0$. The constraints stack the state bounds $\pm S_u U \le \pm(\ldots) - S_xx_0$, the input bounds $\pm U \le \ldots$, and the terminal rows $H_f S_u^{(N)} U \le h_f - H_f A^N x_0$. $H \succ 0$ because $\bar R \succ 0$ and $S_u^\top\bar QS_u \succeq 0$, so a feasible QP has a unique minimiser. $H$ and $G$ are fixed, $f$ and $w$ are affine in $x_0$, $c$ quadratic: the MPC problem is a multiparametric QP, which is why the MPC law is piecewise affine (explicit MPC). The numbers script checks the formulas against 1000 random input sequences at $x_S$ with $N = 5$: 34 constraint rows, smallest eigenvalue of $H$ 0.526, costs agreeing to round-off, and the constraint test agreeing with the rollout in every case.
:::
::::
:::: exercise B.2, KKT conditions
Write them for the condensed QP and for the problem with the states kept as variables; show that without inequalities the latter reduces to the Riccati recursion, and interpret the multipliers.
::: hint
Chapter [[a03]] gives the four conditions; with the states as variables, introduce one multiplier per dynamics row and read the stationarity conditions backwards in time.
:::
::: answer
(a) $U^\star$ is optimal if and only if there is $\mu \ge 0$ with $HU^\star + f + G^\top\mu = 0$, $GU^\star \le w$ and $\mu_i(w - GU^\star)_i = 0$; with affine constraints these are necessary and sufficient, $U^\star$ is unique because $H \succ 0$, $\mu$ need not be. (b) With multipliers $\lambda_{k+1}$ for the dynamics and $\nu_k$, $\mu_k$, $\eta$ for the inequalities, stationarity reads $2Ru_k + B^\top\lambda_{k+1} + G_u^\top\nu_k = 0$, $\lambda_k = 2Qx_k + A^\top\lambda_{k+1} + G_x^\top\mu_k$ and $\lambda_N = 2Px_N + G_x^\top\mu_N + H_f^\top\eta$: the costates run backwards, as in the discrete-time maximum principle. Without inequalities try $\lambda_k = 2P_kx_k$: the $u_k$-condition gives $u_k = -(R + B^\top P_{k+1}B)^{-1}B^\top P_{k+1}Ax_k$ and the $x_k$-condition the Riccati recursion with $P_N = P$; with $P$ from the DARE, $P_k = P$ for all $k$, which is why the MPC equals the LQR inside $\mathcal X_f$. A multiplier is the price of its constraint: if the active set does not change, $\partial J_N^\star / \partial w_i = -\mu_i$, so relaxing constraint $i$ by $\varepsilon$ lowers the optimal cost by about $\mu_i\varepsilon$; C.4 uses this to size slack penalties. The widget below recovers the multipliers at $x_S$ and checks the price: with $N = 5$ the single active constraint is $u_1 \ge -1$, multiplier 0.4944.
:::

::::: exercises
:::: exercise B.3, recursive feasibility by the shifted sequence
Let $x \in \mathcal X_N$ with optimal plan and predicted states. Show that $x^+ = Ax + Bu_0^\star \in \mathcal X_N$. Which conditions are used? Is optimality needed?
::: hint
Build a candidate plan at $x^+$ from the old plan's tail and one move of the local controller.
:::
::: answer
From $x^+ = x_1^\star$ take the shifted plan $(u_1^\star, \ldots, u_{N-1}^\star, -Kx_N^\star)$. Its states $x_2^\star, \ldots, x_N^\star$ lie in $\mathcal X$; since $x_N^\star \in \mathcal X_f$, condition 1 gives $-Kx_N^\star \in \mathcal U$ and condition 2 gives $A_Kx_N^\star \in \mathcal X_f \subseteq \mathcal X$. So $x^+ \in \mathcal X_N$. Neither condition 3 nor optimality is used: any feasible plan has a feasible successor, which makes the shifted plan a valid warm start and fallback (C.3, C.6). The argument does need a plant equal to the model (C.1, C.2).
:::
::::
:::: exercise B.4, Lyapunov decrease and the upper bound
Prove $J_N^\star(x^+) \le J_N^\star(x) - q(x, u_0^\star)$, then $J_N^\star \le V_f$ on $\mathcal X_f$, and say what the bound adds.
::: hint
Price the shifted plan of B.3; for the bound, apply the LQR for $N$ steps from a state of $\mathcal X_f$ and sum condition 3 along it.
:::
::: answer
The shifted plan costs $\tilde J = J_N^\star(x) - q(x, u_0^\star) + [q(x_N^\star, -Kx_N^\star) + V_f(A_Kx_N^\star) - V_f(x_N^\star)]$, where the bracket is at most zero by condition 3, and $J_N^\star(x^+) \le \tilde J$ by optimality. For $x \in \mathcal X_f$ the plan $u_k = -Kx_k$ is feasible by conditions 1 and 2, and summing condition 3 along it gives $\sum_k q(x_k, -Kx_k) + V_f(x_N) \le V_f(x)$, hence $J_N^\star(x) \le V_f(x) \le \lambda_{\max}(P)\|x\|^2$. The lower bound $J_N^\star \ge \lambda_{\min}(Q)\|x\|^2$ and the decrease give $\sum_t\|x(t)\|^2 < \infty$, hence convergence; only the upper bound makes small initial states stay small, $\lambda_{\min}(Q)\|x(t)\|^2 \le J_N^\star(x(t)) \le J_N^\star(x(0)) \le \lambda_{\max}(P)\|x(0)\|^2$ for $x(0) \in \mathcal X_f$. With both bounds quadratic, $J_N^\star(x^+) \le (1 - \lambda_{\min}(Q)/c_2)J_N^\star(x)$ with $c_2 = \lambda_{\max}(P) = 1.911$ on $\mathcal X_f$ and a larger constant on the bounded $\mathcal X_N$: exponential stability.
:::
::::
:::: exercise B.5, invariance of the convex safe set
Each stored state $s_i$ has a stored input and successor $s_i^+ = As_i + Bu_i$, and the target is stored as an equilibrium with $u = 0$. Show that $CS = \operatorname{conv}\{s_i\}$ is control invariant when $\mathcal X$ and $\mathcal U$ are convex. Which step fails for a nonlinear model, and which for a nonconvex $\mathcal X$?
::: hint
Mix the stored inputs with the same weights as the stored states, and let linearity carry the mixture through the dynamics.
:::
::: answer
Write $x = \sum_i\lambda_is_i$ on the simplex and apply $u = \sum_i\lambda_iu_i \in \mathcal U$. By linearity $Ax + Bu = \sum_i\lambda_is_i^+ \in CS$, because every successor is a stored state; and $CS \subseteq \mathcal X$ by convexity. For a nonlinear model the linearity step fails, so only the sampled set stays invariant, which leads to mixed-integer problems or local convexifications (Part 8). For a nonconvex $\mathcal X$, such as lab [[b01]]'s crossing, a convex combination of admissible states can be inadmissible.
:::
::::
:::: exercise B.6, the barycentric terminal cost
With $V_c(x) = \min\{\mathbf J^\top\lambda : S^\top\lambda = x,\ \mathbf 1^\top\lambda = 1,\ \lambda \ge 0\}$, show that (a) $V_c$ is convex on $CS$ with $V_c(s_i) \le J_i$; (b) with $\lambda$ optimal at $x$ and $u = \sum_i\lambda_iu_i$, $V_c(Ax + Bu) \le V_c(x) - q(x, u)$; (c) $V_c \ge J_\infty^\star$ on $CS$.
::: hint
(a) is the value of a linear program with a right-hand side affine in $x$; (b) uses the stored recursion $J_i = q(s_i, u_i) + J_i^+$ and the convexity of $q$; (c) uses that each $J_i$ is the cost of an admissible trajectory.
:::
::: answer
(a) If $\lambda, \lambda'$ are optimal at $x, x'$, then $\theta\lambda + (1 - \theta)\lambda'$ is feasible at $\theta x + (1 - \theta)x'$ with cost $\theta V_c(x) + (1 - \theta)V_c(x')$, so $V_c$ is convex, and piecewise affine as the value of an LP with a right-hand side affine in $x$; choosing $\lambda = e_i$ gives $V_c(s_i) \le J_i$. Geometrically, the lower convex envelope of the points $(s_i, J_i)$. (b) By linearity $Ax + Bu = \sum_i\lambda_is_i^+$, so the same weights on the successors are feasible at $x^+$, and convexity of $q$ gives $q(x, u) \le \sum_i\lambda_iq(s_i, u_i)$; hence $V_c(x^+) \le \sum_i\lambda_iJ_i^+ = \sum_i\lambda_iJ_i - \sum_i\lambda_iq(s_i, u_i) \le V_c(x) - q(x, u)$. With B.5 these are conditions 1 to 3 for $\mathcal X_f = CS$, $V_f = V_c$ and the local controller $\sum_i\lambda_iu_i$, so B.3 and B.4 apply to LMPC unchanged. (c) Each $J_i$ is the cost of an admissible trajectory, so $J_i \ge J_\infty^\star(s_i)$, and $J_\infty^\star$ is convex (linear dynamics, convex constraints and cost); for $\lambda$ optimal at $x$, $V_c(x) = \sum_i\lambda_iJ_i \ge \sum_i\lambda_iJ_\infty^\star(s_i) \ge J_\infty^\star(x)$. The learned terminal cost is pessimistic, which is the mechanism behind the plateau of Part 5; the widget below measures it on random points.
:::

## Engineering judgment {#judgment}

Parts 1 to 6 assumed an exact model, an exact solver and a measured state. What if they fail? Each question has a hint and an answer.

::::: exercises
:::: exercise C.1, model mismatch
The plant is $(A + \Delta A, B + \Delta B)$, the MPC uses $(A, B)$. Which guarantees survive?
::: hint
Find the line of B.3 that says the measured next state equals the predicted one.
:::
::: answer
Strictly, none: every proof used $x^+ = x_1^\star$. With a continuous value function, linear MPC has some inherent robustness, so for small mismatch the state still reaches a neighbourhood of the origin. Near active constraints, however, a small error can push the state out of $\mathcal X_N$, into the doomed states of Part 4. Remedies: a better model, constraint margins, offset-free MPC with an integrating disturbance model and an observer, or a robust design (C.2).
:::
::::
:::: exercise C.2, disturbances
$x^+ = Ax + Bu + w$ with $w \in \mathcal W$ bounded. How can constraint satisfaction and recursive feasibility be guaranteed?
::: hint
Plan for a nominal copy of the system and keep the real state in a set around the plan that the disturbance cannot push it out of.
:::
::: answer
Tube MPC (Mayne, Seron and Raković [[ref:8]]) plans for the nominal model $z^+ = Az + Bv$ and applies $u = v + K(x - z)$. The error $e = x - z$ obeys $e^+ = A_Ke + w$ and stays in a robust positively invariant set $\mathcal E$ with $A_K\mathcal E \oplus \mathcal W \subseteq \mathcal E$. Planning with the tightened sets $\mathcal X \ominus \mathcal E$ and $\mathcal U \ominus K\mathcal E$ makes B.3 apply to $z$, and $x \in z \oplus \mathcal E \subseteq \mathcal X$ for every disturbance sequence. The price is a smaller feasible set and convergence to $\mathcal E$ instead of the origin.
:::
::::
:::: exercise C.3, real-time solvers
The QP must be solved within one sampling period. What are the options, and what if the solver does not finish?
::: hint
B.3 produced a feasible plan without solving anything.
:::
::: answer
Small dense QPs suit warm-started active-set solvers (qpOASES); long horizons favour sparse interior-point (HPIPM) or first-order (OSQP) methods; tiny problems can use the explicit piecewise-affine law of B.1. If the solver stops early, the shifted plan of B.3 is feasible, and any feasible plan that costs no more preserves the decrease of B.4: feasibility implies stability (Scokaert, Mayne and Rawlings [[ref:7]]). As Part 3 showed, a failure flag must be checked, not trusted.
:::
::::
:::: exercise C.4, soft constraints
How should constraints be softened so that the QP is always feasible, and how large must the penalty be?
::: hint
Compare the penalty's slope with the multipliers of B.2.
:::
::: answer
Use $G_xx_k \le g_x + \varepsilon_k$ with $\varepsilon_k \ge 0$ and add $\rho\,\mathbf 1^\top\varepsilon + \varepsilon^\top S\varepsilon$ to the cost, for state constraints only, since input bounds are physical limits. If $\rho$ exceeds the largest multiplier of the hard problem (B.2), the penalty is exact: the soft QP returns the hard solution whenever the hard problem is feasible (Kerrigan and Maciejowski [[ref:9]]). A purely quadratic penalty is never exact. Softening restores feasibility of the QP, not the guarantees.
:::
::::
:::: exercise C.5, estimation and delays
Only $y = Cx + v$ is measured, and the input acts after $d$ steps. What changes?
::: hint
Where does the estimation error enter the proofs, and what is a delay from the model's point of view?
:::
::: answer
An observer, a Kalman filter or moving-horizon estimation which handles constraints, provides $\hat x$. Using $\hat x$ as if it were $x$ is standard, but the separation principle does not extend to constrained MPC: the estimation error acts as a disturbance, which output-feedback tube MPC covers by tightening the constraints. A known delay is handled by prediction: solve from $x(t + d)$, predicted with the inputs already sent. Computation time is a one-step delay of the same kind.
:::
::::
:::: exercise C.6, safety fallbacks
What should the controller do when the QP is infeasible or the solver fails?
::: hint
List what is known to be feasible before any new solve: B.3 and B.5 each provide something.
:::
::: answer
Use layers: the rest of the previous plan, feasible for $N - 1$ steps in the nominal case (B.3) and followed by $-Kx$ inside $\mathcal X_f$; then a softened QP that minimises the violation (C.4); last, a backup controller with its own invariant set, such as maximal braking, certified offline. An independent check like the LP of Part 3 tells "no admissible plan exists" apart from "the solver failed". In LMPC, the stored continuation $u = \sum_i\lambda_iu_i$ of B.5 keeps the state in $CS^j$.
:::
::::
:::::

## Where to go next {#next}

**Robust and stochastic MPC.** Tube MPC (C.2), constraint tightening and min-max formulations for bounded disturbances; chance constraints and stochastic tubes for random ones. See Rawlings, Mayne and Diehl [[ref:2]], chapter 3, and Kouvaritakis and Cannon [[ref:12]].

**Nonlinear and economic MPC.** For nonlinear models, terminal ingredients come from the linearisation at the equilibrium (quasi-infinite-horizon MPC, Chen and Allgöwer [[ref:10]]). Without terminal ingredients, stability can be proved for long enough horizons under controllability assumptions (Grüne and Pannek [[ref:11]]): the route to turning the observations of Part 4 into guarantees. Economic MPC drops positive-definite stage costs and replaces the Lyapunov argument by dissipativity.

**Learning MPC beyond linear systems.** The convex safe set is not invariant for nonlinear dynamics (B.5). The alternatives are a sampled safe set with a mixed-integer terminal constraint, or local convex safe sets with local models identified from data, as in the racing labs [[b03]] and [[b04]] (Rosolia and Borrelli [[ref:5]]).

**Data-driven models.** Identification with error bounds feeds robust MPC, Gaussian-process models provide uncertainty estimates, and methods based on Willems' fundamental lemma replace the model by a Hankel matrix of measured data (Coulson, Lygeros and Dörfler [[ref:14]]).

**Embedded solvers.** OSQP (operator splitting), qpOASES (parametric active set), HPIPM and acados (structure-exploiting interior point and code generation), and explicit MPC by multiparametric programming (Bemporad et al. [[ref:13]]).

**Projects on the course repository.** Add a disturbance $|w_i| \le 0.05$, implement tube MPC, and repeat the grid check. Soften the state constraints with an exact penalty (C.4) and test it under model mismatch. Repeat Part 5 from other first trajectories: does the $N = 2$ plateau move? Replace the package's interior-point solver by an active-set method and rerun the audit of Part 3.

## The code behind it {#code}

The certificate of Part 3 rests on two functions that share no code with the QP solver: the feasibility LP and the controllable-set recursion.

::: code advanced_mpc_lmpc/qp.py:feasibility_margin
The LP adds one variable, the uniform relaxation $s$, to the $n$ decision variables and asks for the smallest $s \ge 0$ that makes every row satisfiable: the inequality rows get $-s$ on their right-hand side through the appended $-1$ column, the equalities become two inequalities each, and the bounds are stacked by the same helper the QP solver uses. SciPy's HiGHS solves it; the returned margin is zero for a feasible constraint set and positive otherwise, a certificate in both directions. Part 3 calls it at every grid state before any QP, and the degenerate vertex $(4, 0.5)$ gets the margin $0$ it deserves.
:::

::: code advanced_mpc_lmpc/polytopes.py:n_step_controllable_sets
Four lines that are Part 2: start from the target intersected with the state box, then repeat "predecessor, then intersect with the box" $N$ times, returning the whole sequence $\mathcal K_0, \ldots, \mathcal K_N$. With the terminal set as the target the sequence is nested and stops growing at $\mathcal C_\infty$ (Part 2); with the box itself as the target it shrinks towards $\mathcal C_\infty$ from outside and its slivers are the doomed states (Part 4). The predecessor is chapter [[a09]]'s Fourier–Motzkin elimination, and the intersection removes redundant rows so that the vertex count stays honest.
:::

## Common pitfalls {#pitfalls}

1. **"A solver flag is a certificate."** A failure flag can be a degenerate QP, a success flag a loose tolerance. Feasibility is decided by an independent LP.
2. **"The QP's objective is the Lyapunov function."** Solvers drop the constant $c$ of B.1; the decrease is checked on the full value $J_N^\star$.
3. **"The plain controller worked from $N = 3$, so it is safe."** It worked on this grid; the decrease inequality still has the wrong sign, and no theorem certifies the horizon at which it starts to work.
4. **"LMPC converges to the optimum."** It converges, monotonically, to some cost; with $N = 2$ that cost is 0.30 percent above the optimum, and nothing in the theory says otherwise.
5. **"Guarantees transfer to the plant."** Every proof used $x^+ = x_1^\star$; C.1 and C.2 say what replaces it.
6. **"A soft constraint restores the guarantee."** It restores the feasibility of the QP; with an exact penalty it reproduces the hard solution when one exists, and otherwise it violates the constraint.

## Check your understanding {#check}

:::: qa
Try to answer each question before opening it.

::: q 1. Why is checking the three terminal conditions at the vertices of $\mathcal X_f$ enough?
Conditions 1 and 2 are linear statements about a convex set, so they hold on the whole set if they hold at its vertices; condition 3 is an identity in $x$ by the DARE.
:::
::: q 2. What is the feasible set of the terminal design, and why is it control invariant?
$\mathcal X_N = \mathcal K_N(\mathcal X_f)$: from any of its states some admissible input reaches $\mathcal K_{N-1} \subseteq \mathcal K_N$.
:::
::: q 3. What does the grid certificate check that the theorem does not already say?
Nothing, when the computer is exact: it checks that the implementation, the solver and the sets agree with the theorem on every grid state, and it would reveal a solver artefact as a positive residual or a lost loop.
:::
::: q 4. Why does the capstone decide feasibility with a linear program?
Because the LP shares no code with the QP solver and gives a margin that certifies both feasibility and infeasibility; a solver's flag does neither.
:::
::: q 5. Which sign does the decrease inequality have without terminal ingredients?
The wrong one: with $V_f = 0$, $J_N^0(x^+) - J_N^0(x) + q(x, u_0^\star) = J_N^0(x^+) - J_{N-1}^0(x^+) \ge 0$.
:::
::: q 6. What is a doomed state?
A state that is feasible for the plain problem now, outside $\mathcal C_\infty$, and bound to leave $\mathcal X$ whatever the inputs.
:::
::: q 7. Why does LMPC with $N = 2$ stall above the optimum?
Its terminal cost $V_c$ over-estimates $J_\infty^\star$ between stored states (B.6c), so a two-step plan that ends anywhere new looks more expensive than replaying the stored trajectory.
:::
::: q 8. What single assumption do all the capstone's guarantees share?
That the plant is the model: $x^+ = x_1^\star$. Part 7 lists what replaces it when that fails.
:::

## The course on one page {#summary}

::: steps
- **LQR terminal ingredients**: $V_f$ decreases with equality, $\mathcal X_f$ is limited by the input bound, and the feasible sets $\mathcal X_N$ are nested, control invariant and equal to $\mathcal C_\infty$ from $N = 5$.
- **Grid certificate**: over 3943 closed-loop QPs, no loss of feasibility, a decrease residual at round-off, and $J_N^\star = V_f$ on $\mathcal X_f$; feasibility certified by an independent LP, which also handles the degenerate vertex $(4, 0.5)$.
- **No terminal ingredients**: $N = 1$ lost feasibility from 100 states of $\mathcal C_\infty$, $N = 2$ accepted doomed states and cost up to $2.15\, J_\infty^\star$. From $N = 3$ on the grid behaved, but without a certificate.
- **Learning MPC**: from $1.69\, J_\infty^\star$ the costs never increased. $N = 4$ reached $J_\infty^\star$, while $N = 2$ and $N = 3$ stalled 0.30 and 0.13 percent above it, because $V_c$ is pessimistic between data.
- **Derivations**: the condensed QP is a multiparametric QP; its KKT system contains the Riccati recursion; the shifted sequence proves feasibility, the terminal decrease proves stability; the convex safe set and the barycentric cost satisfy the same three conditions from data.
- **Judgment**: every proof needs plant equal to model; tubes buy robustness with region; a solver flag is not a certificate; penalties restore feasibility of the QP, not the guarantees; observers add a disturbance; fallbacks are layered.
:::

### The vocabulary, in one table

| Term | Meaning here |
|---|---|
| Terminal ingredients | A terminal set, a terminal cost and a local controller satisfying conditions 1 to 3. |
| $\mathcal X_K$, $\mathcal O_\infty$ | States where the LQR input is admissible; the largest positively invariant subset. |
| Feasible set $\mathcal X_N$ | The controllable set $\mathcal K_N(\mathcal X_f)$; the region of attraction. |
| Doomed state | Feasible for the plain problem now, outside $\mathcal C_\infty$, bound to leave $\mathcal X$. |
| Decrease residual | $J_N^\star(x^+) - J_N^\star(x) + q(x, u)$, at most zero with terminal ingredients. |
| Feasibility LP | The smallest uniform relaxation that makes the QP feasible; zero certifies feasibility. |
| Deadbeat completion | Two inputs that bring the double integrator to the origin exactly. |
| Plateau | An LMPC cost that stops improving because $V_c$ over-estimates the tail away from the data. |
| Multiplier as price | $\partial J^\star / \partial w_i = -\mu_i$ while the active set is unchanged. |
| Tube | The set $z \oplus \mathcal E$ around the nominal plan that contains every disturbed state. |
| Exact penalty | A slack weight above the largest multiplier, so the soft problem reproduces the hard solution. |

**Scope.** A deterministic linear system with polytopic constraints and a quadratic cost, the setting in which every statement above is a theorem; Part 7 says what changes outside it. Every computation on this page runs in the browser with the course's polytope toolkit and interior-point solver; the numbers script reproduces it with the package.
