Kalman filters with JAX

The Kalman filter is sixty years old and still the working engineer's way of turning noisy measurements into a state and an honest uncertainty. This course rebuilds the author's Kalman-Filter-with-JAX workshop as three interactive chapters: the filter and its nonlinear cousins on a tracking problem, a neural network learning the dynamics the model leaves out from inside the filter, and the same learned forecaster facing a year of real air-quality data. Every demo runs in your browser from the same equations as the JAX code, every printed number was reproduced, and the bugs that turned up, a filter that silently returns NaN in 32-bit arithmetic among them, are explained and fixed.

One repository, three experiments, honest numbers

The repository has three scripts and this course follows them in order. The first compares a linear Kalman filter, an extended filter and an unscented filter on synthetic constant-velocity data: the three should agree, and two do, while the third turns to NaN after 33 seconds for a reason worth a whole section. The second puts a small tanh network inside the filter's prediction step and trains it by differentiating through the entire recursion, which JAX makes a one-liner and which the page redoes by hand, in the browser, to the seventh digit. The third applies that forecaster to next-hour nitrogen-dioxide prediction from the UCI air-quality sensors and measures it against persistence and a linear model.

Nothing here is taken on trust. Every number quoted on a chapter page was recomputed from the repository's code and again from the page's own implementation, and where the two disagree the page says which one is wrong. The course is also a worked example of how to read an experiment critically: which loss is being minimised, what the model is evaluated on, and whether the baseline is the right one.

Chapters

Chapter 01 is self-contained and the reference for the other two. Chapter 02 needs its filter and some comfort with neural networks and calculus. Chapter 03 needs nothing beyond 02 and a little scepticism.

  1. 01 The Kalman Filter and Its Nonlinear Cousins The constant-velocity model and its discretised noise, the predict and update equations with a worked first step, the Joseph form, the extended filter's Jacobians, the unscented filter's sigma points and weights, and the gain's convergence to its steady state. All three filters run live on the repository's data. You find The filter cuts the sensor's 0.5 position error to 0.155 and estimates an unmeasured velocity to 0.135, but the repository's unscented filter prints NaN: with the textbook α = 10⁻³ its sigma-point weights are ±10⁶, and 32-bit arithmetic cannot subtract them. α = 1 fixes it.
  2. 02 Learning What the Model Leaves Out A 914-parameter network learns a plant's nonlinear residual from inside a Kalman filter, trained by backpropagation through the recursion, derived by hand and run in the browser against JAX's trace. Then the question the repository skips: does it generalise to a trajectory it never saw? You find The hand-written gradient matches JAX to 5 × 10⁻⁷, and the trained network fits its 50-step rollout to a loss of 0.012, but on a fresh rollout it forecasts with RMSE 8.5 against 2.9 for no residual at all. A bounded plant and honest noise matrices bring it to 1.80 against 2.18.
  3. 03 A Real Series: Next-Hour NO2 A year of hourly air-quality readings from an Italian city, split in time; persistence, a linear model, and the repository's Kalman-MLP forecaster, re-run live with adjustable noise matrices, scored by hour of day and against the diagonal. You find Persistence forecasts the next hour's NO2 with RMSE 25.4; a linear model with the current reading as a feature reaches 24.9; the Kalman-MLP scores 33.7, because its state is a lagged copy of the series. Retuning the filter's noise brings it to 29.4, still behind the baseline nobody trained.

Running it yourself

The chapter pages run everything in the browser. To run the JAX code, download the code (the kalman_jax package, the three scripts, the tests and the requirements), or clone the repository, then from its folder run:

pip install -r requirements.txt
python "Kalman Filter with JAX.py"      # chapter 01: linear KF, EKF, UKF
python "Kalman Filter with DL.py"       # chapter 02: the learned residual
pytest

Chapter 03 needs the UCI Air Quality dataset: download AirQualityUCI.csv from the UCI Machine Learning Repository (CC BY 4.0) into data/raw/, then run python "Air Quality with JAX.py". The two synthetic scripts run in seconds on a CPU; the air-quality training takes about a minute.

Source and further reading

Chapters 01 and 02 use simulated data from known models, so every estimate can be checked against ground truth. Chapter 03 uses the Air Quality dataset of De Vito and colleagues (UCI Machine Learning Repository), 9358 hourly readings of five metal-oxide sensors, temperature and humidity from a polluted Italian street, with reference analyser concentrations as targets. The course is built from the author's public repository; the corrections it proposes, a numerically safe default for the unscented filter, a failing test fixture, and fresh-rollout and baseline evaluations for the learned models, are documented on the chapter pages.
