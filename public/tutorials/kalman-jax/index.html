Kalman filters with JAX

The Kalman filter is sixty years old and still the working engineer's way of turning noisy measurements into a state and an honest uncertainty. This course gathers four of the author's small public repositories on filtering into one sequence: a first filter in twenty lines of NumPy on a simulated vehicle, the filter and its nonlinear cousins in JAX, a neural network learning the dynamics the model leaves out from inside the filter, the same learned forecaster facing a year of real air-quality data, and finally the simplest filter of all written in C, for the day it has to run on a sensor. Every demo runs in your browser from the same equations as the original code, every printed number was reproduced, and the bugs that turned up, a filter that silently returns NaN in 32-bit arithmetic and a C program that wrote a file of zeros among them, are explained and fixed.

Four repositories, five chapters, honest numbers

The sequence follows the author's repositories in order of ambition. kalman_vehicle_tracking is a twenty-line NumPy class applied to a simulated chirp; it improves on the sensor by 10% and gets worse than the sensor near the end, which is the right first lesson about models. Kalman-Filter-with-JAX has three scripts: a comparison of the linear, extended and unscented filters, where the third turns to NaN after 33 seconds for a reason worth a whole section; a tanh network inside the filter's prediction step, trained by differentiating through the entire recursion, which the page redoes by hand in the browser to the seventh digit; and a next-hour nitrogen-dioxide forecaster on the UCI air-quality sensors, measured against persistence. First-Order-Filter-using-C is a coursework program whose committed output file is all zeros; compiling it finds out why, and reading it is a compact C lesson.

Nothing here is taken on trust. Every number quoted on a chapter page was recomputed from the repository's code and again from the page's own implementation, and where the two disagree the page says which one is wrong. The course is also a worked example of how to read an experiment critically: which loss is being minimised, what the model is evaluated on, whether the baseline is the right one, and whether the test could have failed.

Chapters

Chapter 01 needs only Python. Chapter 02 is the reference for the rest and is self-contained. Chapter 03 needs its filter and some comfort with neural networks and calculus; chapter 04 needs 03 and a little scepticism. Chapter 05 needs chapter 01 and any programming language, and teaches the C it uses.

  1. 01 Tracking a Vehicle with a Kalman Filter A first Kalman filter in twenty lines of NumPy: a vehicle's position measured with 5 m of noise, a constant-velocity model, predict and update explained line by line, and the two noise matrices to choose. The repository's tracker runs live with adjustable Q and R. You find The filter cuts the position error from 5.00 to 4.50 m overall but is worse than the raw sensor in the last third of the run, because the motion is a chirp that a constant-velocity model cannot follow; its Q is ten times too small (2.93 m at ten times the scale), and the data file's velocity column describes a different vehicle.
  2. 02 The Kalman Filter and Its Nonlinear Cousins The constant-velocity model and its discretised noise, the predict and update equations with a worked first step, the Joseph form, the extended filter's Jacobians, the unscented filter's sigma points and weights, and the gain's convergence to its steady state. All three filters run live on the repository's data. You find The filter cuts the sensor's 0.5 position error to 0.155 and estimates an unmeasured velocity to 0.135, but the repository's unscented filter prints NaN: with the textbook α = 10⁻³ its sigma-point weights are ±10⁶, and 32-bit arithmetic cannot subtract them. α = 1 fixes it.
  3. 03 Learning What the Model Leaves Out A 914-parameter network learns a plant's nonlinear residual from inside a Kalman filter, trained by backpropagation through the recursion, derived by hand and run in the browser against JAX's trace. Then the question the repository skips: does it generalise to a trajectory it never saw? You find The hand-written gradient matches JAX to 5 × 10⁻⁷, and the trained network fits its 50-step rollout to a loss of 0.012, but on a fresh rollout it forecasts with RMSE 8.5 against 2.9 for no residual at all. A bounded plant and honest noise matrices bring it to 1.80 against 2.18.
  4. 04 A Real Series: Next-Hour NO2 A year of hourly air-quality readings from an Italian city, split in time; persistence, a linear model, and the repository's Kalman-MLP forecaster, re-run live with adjustable noise matrices, scored by hour of day and against the diagonal. You find Persistence forecasts the next hour's NO2 with RMSE 25.4; a linear model with the current reading as a feature reaches 24.9; the Kalman-MLP scores 33.7, because its state is a lagged copy of the series. Retuning the filter's noise brings it to 29.4, still behind the baseline nobody trained.
  5. 05 A First-Order Filter in C The first-order low-pass filter and its exact discretisation, then the C needed to implement it, types, arrays, pointers, return codes and file I/O, read through the author's coursework program line by line. The filter runs live on the program's own recording with an adjustable time constant, and the steady-state Kalman filter is shown to be the same recursion. You find The program's committed output is 250 lines of 0.00 because it filtered the wrong array and read 199 cells past its end; with the bug fixed, its 2 s time constant still attenuates the 1 Hz recording to 8%, and no causal first-order filter brings the recording closer to the clean sine than it already is.

Running it yourself

The chapter pages run everything in the browser. To run the original code, download the code: the kalman_jax package with its three scripts and tests, the vehicle tracker in vehicle/, and the C program with its corrected version in first-order-c/. Or clone the repositories: kalman_vehicle_tracking, Kalman-Filter-with-JAX and First-Order-Filter-using-C. Then:

pip install -r requirements.txt
python vehicle/tracker/vehicle_tracker.py   # chapter 01 (run from vehicle/)
python "Kalman Filter with JAX.py"          # chapter 02: linear KF, EKF, UKF
python "Kalman Filter with DL.py"           # chapter 03: the learned residual
pytest
gcc -Wall -Wextra -o td3 first-order-c/TD3_fixed.c && (cd first-order-c && ../td3)   # chapter 05

Chapter 04 needs the UCI Air Quality dataset: download AirQualityUCI.csv from the UCI Machine Learning Repository (CC BY 4.0) into data/raw/, then run python "Air Quality with JAX.py". The synthetic scripts run in seconds on a CPU; the air-quality training takes about a minute; the C program compiles and runs instantly.

Source and further reading

Chapters 01 to 03 use simulated data from known models, so every estimate can be checked against ground truth. Chapter 04 uses the Air Quality dataset of De Vito and colleagues (UCI Machine Learning Repository), 9358 hourly readings of five metal-oxide sensors, temperature and humidity from a polluted Italian street, with reference analyser concentrations as targets. Chapter 05 uses the recording that ships with the C program. The corrections the course proposes to the repositories, a numerically safe default for the unscented filter, a failing test fixture, fresh-rollout and baseline evaluations for the learned models, a consistent vehicle simulator, and the C program's three bugs, are documented on the chapter pages.
