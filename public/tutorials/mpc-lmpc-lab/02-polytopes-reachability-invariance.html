Polytopes, reachability and invariant sets

A state constraint such as |p| \le 4, |v| \le 3 is not a pair of limits but a set, and once dynamics enter, the questions become geometric: where can the system go, from where can it reach a target, which states can stay safe forever, and which can stay safe under one fixed controller? For linear systems with linear inequalities every one of these is a polytope. Below, they are computed in your browser for the double integrator; click any state to learn whether it can reach the target, how many steps it needs, and whether it is safe at all.

Part 1

Polyhedral geometry

The central idea of the chapter is

\boxed{\text{constraints} + \text{dynamics} \ \Longrightarrow\ \text{geometry in state space}}.

Polyhedra and polytopes. A polyhedron is an intersection of finitely many closed half-spaces, \mathcal P = \{x \in \mathbb R^n : Hx \le h\}; a polytope is a bounded polyhedron. Equivalently, every polytope is the convex hull of finitely many vertices, \mathcal P = \mathrm{conv}\{v_1, \dots, v_M\}. These are the two representations:

\boxed{\mathcal P = \{x : Hx \le h\}} \ \ (\text{H, half-spaces}), \qquad \boxed{\mathcal P = \mathrm{conv}\{v_1, \dots, v_M\}} \ \ (\text{V, vertices}).

Why keep both. The H-form is the language of constraints: |x_1| \le 4, |x_2| \le 3 is

\begin{pmatrix} 1 & 0 \\ -1 & 0 \\ 0 & 1 \\ 0 & -1 \end{pmatrix} x \le \begin{pmatrix} 4 \\ 4 \\ 3 \\ 3 \end{pmatrix},

exactly the format solvers take. The V-form is the language of geometry: a convex combination x = \sum_i \lambda_i v_i, \lambda_i \ge 0, \sum_i \lambda_i = 1, is what plotting, convex combinations and low-dimensional Minkowski sums want. Converting is conceptually simple and computationally expensive in high dimension: H to V is vertex enumeration, V to H a convex-hull computation. The notebook builds a five-sided polygon from its vertices, recovers five half-spaces with unit normals, and recovers the vertices again from those.

Membership. For an H-polytope, x \in \mathcal P \iff Hx \le h componentwise: a few inner products. It is used constantly, to check a simulated state, to check whether one set's vertices lie in another, and to detect convergence of set iterations.

Redundant inequalities. Some rows of Hx \le h may be implied by the others: x_1 \le 1 already implies x_1 \le 2. To test row i, solve the linear program \max_x H_i x subject to all the other rows; if the maximum is at most h_i, row i changes nothing and can be dropped. The notebook's unit box with a fifth row x_1 \le 2 reduces from 5 rows to 4. Redundancy reduction matters because repeated intersections and predecessor operations breed unnecessary half-spaces. (One care the course's code takes: each row is tested against the rows still kept, not all original rows, otherwise two identical rows would each be implied by the other and both would be dropped, enlarging the set.)

What is a control-invariant set?

In plain words: a region of state space from which, wherever you are in it, some admissible input keeps you in it for the next step, and therefore, repeating the argument, forever.

More precisely: \mathcal C is control invariant for x^+ = Ax + Bu, u \in \mathcal U, if \forall x \in \mathcal C\ \exists u \in \mathcal U : Ax + Bu \in \mathcal C. The input may differ at every state. Its maximal subset of a constraint set \mathcal X is the fixed point of \mathcal C_{j+1} = \mathcal X \cap \mathrm{Pre}_{\mathcal U}(\mathcal C_j) from \mathcal C_0 = \mathcal X, where \mathrm{Pre}_{\mathcal U}(\mathcal S) = \{x : \exists u \in \mathcal U,\ Ax + Bu \in \mathcal S\} is the controlled predecessor, a projection. Membership is a nominal certificate that the constraints can be kept forever.

Part 2

Basic set operations

Intersection. If \mathcal P_1 = \{x : H_1 x \le h_1\} and \mathcal P_2 = \{x : H_2 x \le h_2\}, then

\boxed{\mathcal P_1 \cap \mathcal P_2 = \Big\{ x : \begin{pmatrix} H_1 \\ H_2 \end{pmatrix} x \le \begin{pmatrix} h_1 \\ h_2 \end{pmatrix} \Big\}} :

stack the inequalities. This is why H-representations are so natural in constrained control.

Affine images. M\mathcal X + c = \{Mx + c : x \in \mathcal X\} is again a polytope, and in V-form it is immediate: \mathrm{conv}\{v_i\} \mapsto \mathrm{conv}\{Mv_i + c\}. It is how a set is propagated through linear dynamics.

Linear preimages. The preimage of \mathcal S under x \mapsto Ax is A^{-1}(\mathcal S) = \{x : Ax \in \mathcal S\}, an inverse image of a set that does not require A to be invertible. If \mathcal S = \{y : H_S y \le h_S\}, then Ax \in \mathcal S means H_S A x \le h_S, so

\boxed{A^{-1}(\mathcal S) = \{x : (H_S A)\, x \le h_S\}},

the basic autonomous predecessor operation: multiply the rows, keep the right-hand sides.

Minkowski sum. \mathcal X \oplus \mathcal Y = \{x + y : x \in \mathcal X,\ y \in \mathcal Y\}. In low dimension: enumerate both vertex sets, form all pairwise sums, take the hull. Intuitive, and scaling poorly, since the candidate pairs multiply. Minkowski sums appear in forward reachable sets, in disturbance propagation and in algebraic predecessor constructions.

Projection and existential variables. Suppose a set is described in the augmented variable z = (x, u) by \mathcal Z = \{(x, u) : G_x x + G_u u \le g\}. Its projection onto x is

\boxed{\mathrm{Proj}_x(\mathcal Z) = \{x : \exists u \text{ such that } (x, u) \in \mathcal Z\}}.

The \exists u is exactly what makes projection the key operation of set-based control: keep the state if at least one admissible input satisfies the required inequalities. Conceptually simple; eliminating variables from a polyhedron can be expensive.

Part 3

Reachability and predecessor sets

The model. x^+ = Ax + Bu with x \in \mathcal X, u \in \mathcal U. Two complementary questions: starting from a set \mathcal S, where can the system go in one step (the forward reachable or Post set)? And from which states can it reach \mathcal S in one step (the predecessor set)?

Forward reachable set.

\mathrm{Post}(\mathcal S) = \{Ax + Bu : x \in \mathcal S,\ u \in \mathcal U\} = \boxed{A\mathcal S \oplus B\,\mathcal U}.

Controlled predecessor.

\boxed{\mathrm{Pre}_{\mathcal U}(\mathcal S) = \{x \in \mathcal X : \exists u \in \mathcal U \text{ such that } Ax + Bu \in \mathcal S\}}.

Read the quantifiers: for every x in the predecessor there exists some admissible u that sends it into \mathcal S, and that u may depend on x. It is not the claim that one input works for every state.

The canonical construction is a projection. With \mathcal S = \{y : H_S y \le h_S\}, the condition Ax + Bu \in \mathcal S reads H_S A x + H_S B u \le h_S. Build the augmented set

\mathcal Z = \{(x, u) : H_S A x + H_S B u \le h_S,\ x \in \mathcal X,\ u \in \mathcal U\}, \qquad \boxed{\mathrm{Pre}_{\mathcal U}(\mathcal S) = \mathrm{Proj}_x(\mathcal Z)}.

Predecessor computation is fundamentally a projection problem.

The equivalent Minkowski view. Ax + Bu \in \mathcal S means Ax \in \mathcal S - Bu, and letting u range over \mathcal U, Ax \in \mathcal S \oplus (-B\,\mathcal U). Hence

\boxed{\mathrm{Pre}_{\mathcal U}(\mathcal S) = A^{-1}\big( \mathcal S \oplus (-B\,\mathcal U) \big)} :

enlarge the target by every admissible opposite control effect, then pull it back through the dynamics. Projection and Minkowski sum describe the same object.

The exact scalar-input predecessor by Fourier–Motzkin elimination. This is what the course's code does. Write every row of the target condition and the input bounds as \alpha_i^\top x + \beta_i u \le \gamma_i. Rows with \beta_i > 0 are upper bounds u \le (\gamma_i - \alpha_i^\top x) / \beta_i; rows with \beta_j < 0 are lower bounds u \ge (\gamma_j - \alpha_j^\top x) / \beta_j. An admissible u exists exactly when every lower bound is below every upper bound, so for every pair,

\frac{\gamma_j - \alpha_j^\top x}{\beta_j} \le \frac{\gamma_i - \alpha_i^\top x}{\beta_i},

an inequality in x alone; rows with \beta = 0 pass through unchanged. For the notebook's box target, four target rows plus two input bounds give three lower and three upper bounds, hence nine pairwise rows, of which six survive redundancy removal. Exercise 6 does one pair by hand.

A witness input. Membership in the predecessor must be backed by an actual input: for a fixed x, find u \in [u_{\min}, u_{\max}] with H_S(Ax + Bu) \le h_S, a one-variable feasibility problem whose answer is an interval. The notebook takes x = (-0.65, 0.45), outside the target but inside the predecessor, and its linear program returns u = -0.1, sending the state to (-0.25, 0.35), on the target's boundary. The whole interval of witnesses is [-0.4, -0.1]; the solver happened to return its upper end.

Part 4

Finite-step controllability

Backward recursion to a target. Let \mathcal K_0 = \mathcal S and

\boxed{\mathcal K_{j+1} = \mathcal X \cap \mathrm{Pre}_{\mathcal U}(\mathcal K_j)}.

\mathcal K_1 holds the states that reach the target in one admissible step, \mathcal K_2 those that reach \mathcal K_1 in one step and hence the target in at most two, and so on: \mathcal K_N is the N-step controllable set, subject to the state and input constraints built into the predecessor. "At most" needs the sets to be nested, \mathcal K_j \subseteq \mathcal K_{j+1}, which holds here because the target box is itself control invariant (checked: every vertex of each \mathcal K_j lies in \mathcal K_{j+1}). For the notebook's target [-0.25, 0.25]^2 and six steps, the sets have 4, 6, 8, 8, 6, 10 and 10 vertices; the demo at the top draws them.

A minimum-step map. N_{\min}(x) = \min\{j : x \in \mathcal K_j\} is a crude distance to the target in control steps, not a Euclidean distance: two geometrically close states can need different numbers of steps because of velocity, saturation and the state constraints. The map reflects the physics of controllability. On the notebook's grid of 161 by 121 states, 4088 of 19 481 lie in the box but not in \mathcal K_6; the demo shades N_{\min} and reports it for the probe.

Reachable versus controllable-to-target. Easy to confuse. The forward reachable set \mathcal R_1 = A\mathcal X_0 \oplus B\,\mathcal U answers "where can I go?"; the predecessor answers "where can I start if I want to get there?". They are dual viewpoints, not the same operation, even though for the symmetric example of Part 3 one is the mirror image of the other.

Part 5

Invariance

Positive invariance. For the autonomous system x^+ = A_{\mathrm{cl}} x, a set \Omega is positively invariant if

\boxed{x \in \Omega \ \Longrightarrow\ A_{\mathrm{cl}} x \in \Omega}, \qquad \text{equivalently } A_{\mathrm{cl}} \Omega \subseteq \Omega :

once a trajectory enters, the fixed dynamics keep it there forever.

The maximal positively invariant subset of a constraint set \mathcal S is \mathcal O_\infty(\mathcal S) = \bigcap_{k=0}^{\infty} A_{\mathrm{cl}}^{-k} \mathcal S: in \mathcal S now, after one step, after two, forever. The practical fixed-point iteration [3] is

\Omega_0 = \mathcal S, \qquad \boxed{\Omega_{j+1} = \mathcal S \cap A_{\mathrm{cl}}^{-1}(\Omega_j)}, \qquad \text{stop when } \Omega_{j+1} = \Omega_j .

A subtle but essential point: input constraints under a fixed feedback. With u = -Kx, a state may be inside \mathcal X while the feedback demands more than the actuator can give. The admissible closed-loop state set is therefore not \mathcal X but

\boxed{\mathcal X_K = \{x \in \mathcal X : u_{\min} \le -Kx \le u_{\max}\}},

and the maximal invariant set for the fixed controller must be computed inside \mathcal X_K. For the LQR gain K = (0.7396, 1.2604) (closed-loop eigenvalues 0.185 \pm 0.274\,i) and |u| \le 1, \mathcal X_K has 6 vertices, and the iteration stops after 2 steps with \mathcal O_\infty of 4 vertices: the parallelogram (\pm 2.40, \mp 2.20), (\pm 2.20, \mp 0.50).

Why the iteration removes states. \Omega_0 = \mathcal X_K is every state that is admissible now. \Omega_1 removes those that leave the admissible set after one step; \Omega_2 those that survive one step and fail later; and so on until nothing more needs removing. The algorithm converts a one-step constraint set into an infinite-time safe set for that closed-loop law. Choose "fixed-LQR invariant iteration" in the demo and drag j.

Control invariance. Back to x^+ = Ax + Bu. A set \mathcal C is control invariant if

\boxed{\forall x \in \mathcal C,\ \exists u \in \mathcal U \ \text{such that}\ Ax + Bu \in \mathcal C}.

The order of the quantifiers matters enormously: for each state in the set, at least one admissible input keeps the next state in the set, and the input may differ at every state. A fixed controller commits to one action-selection rule; control invariance keeps the freedom to choose state by state, so a control-invariant set can be larger than the invariant set of any one feedback law.

The maximal control-invariant subset of \mathcal X is the fixed point of

\mathcal C_0 = \mathcal X, \qquad \boxed{\mathcal C_{j+1} = \mathcal X \cap \mathrm{Pre}_{\mathcal U}(\mathcal C_j)} :

keep the states that satisfy the constraints now and have an admissible input into the current candidate; repeat. For the double integrator with |u| \le 1 it converges in 4 iterations to a 10-vertex set \mathcal C_\infty (area 39.3 of the box's 48), and every vertex of the LQR's \mathcal O_\infty (area 7.3) lies inside it: freedom to choose enlarges the safe set more than fivefold. With |u| \le 0.4 (exercise 10) the areas fall to 27.1 and 1.2.

A control-invariant set is a one-step feasibility certificate. If x \in \mathcal C_\infty, some admissible u gives x^+ \in \mathcal C_\infty; since the next state is in the same set, the argument repeats, and the constraints can be maintained indefinitely. The qualification: under the nominal model used to compute the set. With model error or disturbances, nominal invariance alone is not robustness.

Part 6

Geometry of safety and feasibility

Target reachability and invariance are different concepts. A finite-step controllable set answers "can I reach the target within so many steps?"; an invariant set answers "can I remain admissible forever?". A state can be safe indefinitely but far from the target, able to reach the target quickly, immediately admissible but doomed to violate a constraint later, or outside the safe kernel while satisfying every current constraint. Set-based analysis carries more information than checking the current state against a box.

Constraint boundaries are not all equally dangerous. The states (3.8, -1) and (3.8, 2.5) are equally close to the position boundary p = 4. The first is moving inward; the second is rushing at the wall. The sets know: the notebook checks four states, and the demo's probe reproduces every answer.

All four satisfy the box constraints now. Two have no admissible future at all: (3.8, 2.5) will cross p = 4 next step whatever u is (p^+ = 3.8 + 2.5 + 0.5u \ge 5.8), and (-3.5, -2.2) likewise at the other wall. None is safe under the LQR law, whose admissible region is the thin parallelogram.

Computing a safe action at a state. Control invariance says an admissible action exists; it does not say which. One simple policy for x \in \mathcal C_\infty:

\min_u\ u^2 \quad \text{subject to}\quad Ax + Bu \in \mathcal C_\infty, \quad u_{\min} \le u \le u_{\max},

the smallest input that keeps the next state inside. For a scalar input the constraints cut an interval out of [u_{\min}, u_{\max}], and the answer is 0 projected onto it. At x = (3, 0.8) the feasible interval is [-1, -0.0667], so the minimum-effort safe input is u = -0.0667, sending the state to (3.767, 0.733), still inside. The invariant set supplies the guarantee; the secondary objective chooses among safe actions. Click (3, 0.8) in the demo to see it.

Part 7

Numerical complexity and representation choices

Representation switching is not cosmetic. Each operation favours a form, and a set-based algorithm switches repeatedly; the conversions can dominate the cost.

OperationConvenient representation
membership test, linear constraints, intersection, autonomous preimageH
plotting, affine image, Minkowski sum (low dimension), convex combinationsV
projectiondepends on the algorithm

Why exact set computations become expensive. A polytope may have many vertices even with a compact H-form (vertex enumeration); intersections and elimination generate many inequalities (facet growth); a naive Minkowski sum considers N_{\mathcal X} N_{\mathcal Y} vertex pairs; Fourier–Motzkin elimination is notoriously prone to generating redundant rows (for the nine pairwise rows of Part 3, three were redundant already in two dimensions); and reachability and invariance apply all of these many times over. Exact explicit polytopes are excellent teaching tools and practical for many low-dimensional systems; higher-dimensional problems need implicit, approximate or optimisation-based representations [2].

Numerical equality of polytopes. Two H-representations can describe the same set with completely different rows: scaled duplicates, redundant facets, a different order. Comparing H_1 and H_2 is not a set-equality test. In two dimensions the course checks equality geometrically: every vertex of each set lies in the other. That is the test that stops the fixed-point iterations above.

Part 8

Common conceptual pitfalls

  1. "Reachable set = predecessor set." No. \mathrm{Post}(\mathcal S) propagates forward from \mathcal S; \mathrm{Pre}_{\mathcal U}(\mathcal S) works backward from it.
  2. "A^{-1}(\mathcal S) means matrix inversion." Not necessarily. It is the set preimage \{x : Ax \in \mathcal S\}, defined for singular A too.
  3. "Control invariance means one input works for the whole set." No. The statement is \forall x \in \mathcal C,\ \exists u; the input may depend on the state.
  4. "Satisfying constraints now implies future safety." No. A state may lie in \mathcal X but outside \mathcal C_\infty: admissible now, with no admissible strategy that preserves the constraints forever.
  5. "Stable feedback automatically respects constraints." No. A stabilising K can command u = -Kx beyond the actuator limits; the fixed-controller invariant set must include input admissibility.
  6. "An invariant set is automatically robust." Not unless uncertainty is built into its construction. The sets here are nominal.
Part 9

Check your understanding

Try to answer each question before opening it.

1. What is the difference between a polyhedron and a polytope?

A polyhedron is an intersection of finitely many half-spaces and may be unbounded. A polytope is a bounded polyhedron, equivalently the convex hull of finitely many vertices.

2. Why is the H-representation convenient in constrained control?

State and input constraints are naturally linear inequalities, intersections are obtained by stacking rows, and membership is the evaluation of Hx \le h.

3. Define the controlled predecessor precisely.

\mathrm{Pre}_{\mathcal U}(\mathcal S) = \{x \in \mathcal X : \exists u \in \mathcal U,\ Ax + Bu \in \mathcal S\}.

4. Why is predecessor computation a projection problem?

One first builds the set of state–input pairs (x, u) satisfying the target and admissibility conditions, then keeps the states for which at least one such input exists. Eliminating u is projection onto the x coordinates.

5. Explain the Minkowski interpretation of the predecessor.

The existence of some u \in \mathcal U with Ax + Bu \in \mathcal S is equivalent to Ax \in \mathcal S \oplus (-B\,\mathcal U). The preimage through A, intersected with \mathcal X, is the predecessor.

6. What does the N-step controllable set mean?

The states from which an admissible input sequence reaches the target within the backward recursion's horizon while respecting the constraints built into the construction.

7. Define positive invariance.

For x^+ = A_{\mathrm{cl}} x, \Omega is positively invariant if x \in \Omega implies A_{\mathrm{cl}} x \in \Omega.

8. Define control invariance and state the quantifiers.

For every state in the set there exists at least one admissible input sending the next state back into the set: \forall x \in \mathcal C,\ \exists u \in \mathcal U : Ax + Bu \in \mathcal C.

9. Why is a maximal control-invariant set usually larger than the invariant set of one fixed controller?

Control invariance may choose a different admissible input at every state; a fixed controller commits to one law and has less freedom.

10. Why must input constraints be included when computing a closed-loop invariant set?

A trajectory may stay inside the state constraints while the feedback demands an inadmissible actuator command. The admissible closed-loop set must enforce both.

11. Why can exact polytope calculations become expensive?

Vertex and facet counts grow under conversion, Minkowski sums, projection and repeated recursion, and variable elimination generates many redundant inequalities.

12. What does membership in a control-invariant set certify?

Under the nominal model and the stated constraints, that an admissible input exists keeping the next state in the same set, so the argument repeats indefinitely.

Part 10

Exercises

Each exercise has a hint and a solution; the code runs after the notebook's cells. Try first, then peek.

  1. H-representation. Write -2 \le x_1 \le 3, -1 \le x_2 \le 4 as Hx \le h.
    Hint

    Each lower bound becomes a row with a minus sign.

    Solution
    H = \begin{pmatrix} 1 & 0 \\ -1 & 0 \\ 0 & 1 \\ 0 & -1 \end{pmatrix}, \qquad h = \begin{pmatrix} 3 \\ 2 \\ 4 \\ 1 \end{pmatrix},

    which is HPolytope.box([-2, -1], [3, 4]) up to the row order.

  2. Redundant facet. Add x_1 \le 5 to the previous set and prove it redundant by solving the corresponding LP conceptually.
    Hint

    Maximise x_1 over the other four rows.

    Solution

    The LP \max x_1 subject to the four box rows attains 3 (at the right edge), and 3 \le 5, so the new row is implied and remove_redundancy drops it.

    P_ex = HPolytope(np.vstack([HPolytope.box([-2, -1], [3, 4]).H, [[1.0, 0.0]]]), np.r_[HPolytope.box([-2, -1], [3, 4]).h, 5.0])
print(len(P_ex.h), "->", len(P_ex.remove_redundancy().h))   # 5 -> 4
  3. Affine image. With M = \begin{pmatrix} 1 & 1 \\ 0 & 2 \end{pmatrix} and \mathcal X the unit square [0, 1]^2, compute the transformed vertices of M\mathcal X.
    Hint

    Map the four corners.

    Solution

    (0,0) \mapsto (0,0), (1,0) \mapsto (1,0), (1,1) \mapsto (2,2), (0,1) \mapsto (1,2): a parallelogram of area |\det M| = 2.

    M_ex = np.array([[1.0, 1.0], [0.0, 2.0]])
print(affine_image_2d(HPolytope.box([0, 0], [1, 1]), M_ex).vertices_2d())   # (0,0), (1,0), (2,2), (1,2) in some order
  4. Minkowski sum. For the intervals \mathcal A = [-2, 1] and \mathcal B = [-1, 3], compute \mathcal A \oplus \mathcal B, then generalise to axis-aligned boxes.
    Hint

    Smallest possible sum, largest possible sum.

    Solution

    [-2, 1] \oplus [-1, 3] = [-3, 4]: lower bounds add and upper bounds add. For boxes the same happens coordinate by coordinate, because a box is a product of intervals: [l_1, u_1] \times [l_2, u_2] \oplus [l_1', u_1'] \times [l_2', u_2'] = [l_1 + l_1', u_1 + u_1'] \times [l_2 + l_2', u_2 + u_2']. Check in the widget of Part 2 by comparing the box-plus-diamond result's extreme coordinates with the sums of the operands' extremes.

  5. Autonomous preimage. If \mathcal S = \{x : H_S x \le h_S\} and x^+ = Ax, derive the H-representation of \mathrm{Pre}(\mathcal S).
    Hint

    Substitute x^+ into the membership condition.

    Solution

    x \in \mathrm{Pre}(\mathcal S) \iff Ax \in \mathcal S \iff H_S A x \le h_S, so \mathrm{Pre}(\mathcal S) = \{x : (H_S A)\, x \le h_S\}: the rows are multiplied by A, the right-hand sides are unchanged, and A need not be invertible. This is linear_preimage.

  6. Fourier–Motzkin elimination. From \alpha_1^\top x + 2u \le \gamma_1 and \alpha_2^\top x - u \le \gamma_2, eliminate u and derive one inequality in x alone.
    Hint

    The first row bounds u above, the second bounds it below.

    Solution

    Row 1: u \le (\gamma_1 - \alpha_1^\top x)/2. Row 2: u \ge \alpha_2^\top x - \gamma_2. A u exists iff the lower bound is below the upper: \alpha_2^\top x - \gamma_2 \le (\gamma_1 - \alpha_1^\top x)/2, that is

    (\alpha_1 + 2\alpha_2)^\top x \le \gamma_1 + 2\gamma_2 .

    This is exactly one row of the predecessor_scalar_input loop, with \beta_1 = 2 and \beta_2 = -1.

  7. Quantifiers. Explain the difference between \forall x \in \mathcal C,\ \exists u \in \mathcal U and \exists u \in \mathcal U,\ \forall x \in \mathcal C. Which defines control invariance?
    Hint

    In which one may u depend on x?

    Solution

    In \forall x\ \exists u, the input is chosen after the state is known and may differ from state to state: that is control invariance, and what a feedback law or an MPC does. In \exists u\ \forall x, one single input must work for every state in the set at once, a far stronger and rarely true statement: for the double integrator no single u keeps both (3.8, 0.5) and (-3.8, -0.5) inside \mathcal C_\infty: the first needs p^+ = 4.3 + 0.5u \le 4, so u \le -0.6, and the second needs p^+ = -4.3 + 0.5u \ge -4, so u \ge 0.6. The second implies the first, never the reverse.

  8. Fixed feedback. For u = -Kx with |u| \le 1, derive the two half-space inequalities defining the input-admissible state region.
    Hint

    Write |{-Kx}| \le 1 as two linear inequalities.

    Solution

    -Kx \le 1 and Kx \le 1: rows -K and K with right-hand sides 1 and 1. For the notebook's K = (0.7396, 1.2604) these are the two sloped edges of \mathcal X_K; intersected with the box they cut off its top-left and bottom-right corners, where the LQR would demand |u| > 1. This is closed_loop_admissible_set_scalar_input.

  9. Invariant-set recursion. Starting with \Omega_0 = \mathcal S, explain why \Omega_1 = \mathcal S \cap A^{-1}(\mathcal S) contains exactly the states satisfying the constraint at times 0 and 1, and extend the interpretation to \Omega_2.
    Hint

    Unfold A^{-1}(\Omega_1).

    Solution

    x \in \mathcal S is the constraint at time 0; x \in A^{-1}(\mathcal S) means Ax \in \mathcal S, the constraint at time 1. Their intersection is exactly "satisfied at 0 and 1". Then \Omega_2 = \mathcal S \cap A^{-1}(\Omega_1) = \mathcal S \cap A^{-1}(\mathcal S) \cap A^{-2}(\mathcal S): satisfied at 0, 1 and 2. In general \Omega_j = \bigcap_{k=0}^{j} A^{-k}\mathcal S, and the fixed point is the infinite intersection \mathcal O_\infty. In the demo's LQR mode, \Omega_1 already removes the corners of \mathcal X_K and \Omega_2 = \Omega_1.

    Solution

    With less authority, everything shrinks: \mathcal K_6 falls from area 38.1 to 17.4, since fewer states can be brought to the target in six steps; \mathcal C_\infty from 39.3 to 27.1, now taking 7 iterations and 14 vertices, because a cart moving at speed v needs v / 0.4 steps to stop and the position it covers meanwhile must fit in the box, which cuts the corners deeper; and the LQR's \mathcal O_\infty collapses from 7.3 to 1.2, since \mathcal X_K = \{|{-Kx}| \le 0.4\} is a strip only 0.4 wide in the Kx direction. The fixed law is punished most, because it cannot trade a smaller input for a longer manoeuvre.

Part 11

The chapter on one page

  1. Two faces of a polytope: \{x : Hx \le h\} for constraints and membership, \mathrm{conv}\{v_i\} for geometry; converting is the expensive part.
  2. Operations: intersection stacks rows; images map vertices; preimages multiply rows by A; Minkowski sums add vertices; projection is the "there exists".
  3. Forward and backward: \mathrm{Post}(\mathcal S) = A\mathcal S \oplus B\,\mathcal U; \mathrm{Pre}_{\mathcal U}(\mathcal S) = A^{-1}(\mathcal S \oplus (-B\,\mathcal U)), a projection, computed by Fourier–Motzkin elimination.
  4. Controllable sets: \mathcal K_{j+1} = \mathcal X \cap \mathrm{Pre}_{\mathcal U}(\mathcal K_j), nested when the target is control invariant; N_{\min} is distance in steps, not metres.
  5. Invariance: positive, x \in \Omega \Rightarrow A_{\mathrm{cl}} x \in \Omega, computed inside \mathcal X_K; control, \forall x\ \exists u, the larger set.
  6. The numbers: with |u| \le 1, \mathcal C_\infty has 10 vertices after 4 iterations and area 39.3; the LQR's \mathcal O_\infty has 4 after 2 and area 7.3.
  7. What membership certifies: a nominal, repeatable one-step feasibility guarantee, nothing about disturbances.

Part 12

Scope and references

Scope. This chapter covers the set computations behind constrained linear control: H- and V-representations, redundancy removal, intersections, affine images, preimages, Minkowski sums and projection; forward reachable sets and controlled predecessors; finite-step controllable sets; and maximal positively invariant and control-invariant sets, read as feasibility certificates. All computations are exact and nominal, in two dimensions with a scalar input so that every set can be drawn. Robust invariance and high-dimensional set computation are outside its scope.
