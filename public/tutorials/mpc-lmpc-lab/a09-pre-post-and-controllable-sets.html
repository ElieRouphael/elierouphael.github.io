Pre, Post and controllable sets

Once dynamics act on a constraint set, two questions come before any controller: where can the system go from here in one step, and from where can it reach a given set? The first is a forward image, the second a backward one, and for a linear system with a polytope of inputs both are polytopes, computed exactly by the operations of the previous chapter. Repeating the backward question gives the states that can reach a target within N steps, the first shape of an MPC feasible set. Below, click any state to learn how many steps it needs and which first move will do.

Part 1

The forward reachable set

The model. x^+ = Ax + Bu with x \in \mathcal X, u \in \mathcal U, the canonical cart throughout. Two complementary questions: starting from a set \mathcal S, where can the system go in one step? And from which states can it reach \mathcal S in one step?

Forward. The one-step reachable set, or Post set, is the image of \mathcal S under the dynamics with every admissible input:

\mathrm{Post}(\mathcal S) = \{Ax + Bu : x \in \mathcal S,\ u \in \mathcal U\} = \boxed{A\mathcal S \oplus B\,\mathcal U}.

An affine image and a Minkowski sum, both from chapter A8. For a scalar input, B\,\mathcal U is the segment from -u_{\max} B to u_{\max} B, so \mathrm{Post}(\mathcal S) is the hull of the 2M points Av_i \pm u_{\max} B, one pair per vertex of \mathcal S. For the small box \mathcal S = [-0.4, 0.4] \times [-0.35, 0.35] of the widget in Part 3, that is 8 candidate points and a 6-vertex result of area 2.86, more than the box's 1.12: the dynamics shear the box along the position axis and the input stretches it along B.

What are Post and Pre?

In plain words: Post answers "where can I get to from here?"; Pre answers "where must I start to get there?". Post pushes a set forward through the dynamics; Pre pulls a set back through them, keeping only the states from which some admissible input works.

More precisely: \mathrm{Post}(\mathcal S) = A\mathcal S \oplus B\,\mathcal U and \mathrm{Pre}_{\mathcal U}(\mathcal S) = \{x \in \mathcal X : \exists u \in \mathcal U,\ Ax + Bu \in \mathcal S\}. For the autonomous system x^+ = A_{\mathrm{cl}} x the predecessor is the plain preimage A_{\mathrm{cl}}^{-1}(\mathcal S) = \{x : H_S A_{\mathrm{cl}} x \le h_S\}.

\mathrm{Post}(\mathcal S)
One step forward from everywhere in \mathcal S: an image.
\mathrm{Pre}_{\mathcal U}(\mathcal S)
One step back into \mathcal S with some admissible input: a projection.
Witness

Part 2

The controlled predecessor, two ways

Backward.

\boxed{\mathrm{Pre}_{\mathcal U}(\mathcal S) = \{x \in \mathcal X : \exists u \in \mathcal U \text{ such that } Ax + Bu \in \mathcal S\}}.

Read the quantifiers: for every x in the predecessor there exists some admissible u that sends it into \mathcal S, and that u may depend on x. It is not the claim that one input works for every state.

As a projection. With \mathcal S = \{y : H_S y \le h_S\}, the condition Ax + Bu \in \mathcal S reads H_S A x + H_S B u \le h_S. Build the augmented set in (x, u) and project it onto x:

\mathcal Z = \{(x, u) : H_S A x + H_S B u \le h_S,\ x \in \mathcal X,\ u \in \mathcal U\}, \qquad \boxed{\mathrm{Pre}_{\mathcal U}(\mathcal S) = \mathrm{Proj}_x(\mathcal Z)}.

Predecessor computation is fundamentally a projection problem, the "there exists" of chapter A8.

As a Minkowski sum. Ax + Bu \in \mathcal S means Ax \in \mathcal S - Bu, and letting u range over \mathcal U, Ax \in \mathcal S \oplus (-B\,\mathcal U). Hence

\boxed{\mathrm{Pre}_{\mathcal U}(\mathcal S) = A^{-1}\big( \mathcal S \oplus (-B\,\mathcal U) \big)} :

enlarge the target by every admissible opposite control effect, then pull it back through the dynamics. Projection and Minkowski sum describe the same object; the course's code uses the projection, by the elimination below, because it stays in the H-representation from start to finish.

Part 3

Fourier–Motzkin elimination, and a witness input

The exact scalar-input predecessor. Write every row of the target condition and of the input bounds as \alpha_i^\top x + \beta_i u \le \gamma_i. Rows with \beta_i > 0 are upper bounds on the input, u \le (\gamma_i - \alpha_i^\top x) / \beta_i; rows with \beta_j < 0 are lower bounds, u \ge (\gamma_j - \alpha_j^\top x) / \beta_j. An admissible u exists exactly when every lower bound is below every upper bound, so for every pair,

\frac{\gamma_j - \alpha_j^\top x}{\beta_j} \le \frac{\gamma_i - \alpha_i^\top x}{\beta_i},

an inequality in x alone; rows with \beta = 0 pass through unchanged. For the small box target, the four rows have u-coefficients H_S B = (0.5, 1, -0.5, -1); with the two input bounds that is three upper and three lower bounds, hence nine pairwise rows, of which six survive redundancy removal. Exercise 1 does one pair by hand.

A witness input. Membership in the predecessor must be backed by an actual input: for a fixed x, the rows above are an interval of admissible u, the intersection of the lower bounds and the upper bounds with [-u_{\max}, u_{\max}]. Take x = (-0.65, 0.45), outside the target but inside the predecessor: the interval is u \in [-0.4, -0.1]. A linear program with a zero objective, asked only for feasibility, returns u = -0.1, the upper end, which sends the state to (-0.25, 0.35), on the target's boundary; the other end sends it to (-0.4, 0.05), also inside. The widget draws both.

Part 4

Finite-step controllability

The backward recursion. Let \mathcal K_0 = \mathcal S and

\boxed{\mathcal K_{j+1} = \mathcal X \cap \mathrm{Pre}_{\mathcal U}(\mathcal K_j)}.

\mathcal K_1 holds the states that reach the target in one admissible step, \mathcal K_2 those that reach \mathcal K_1 in one step and hence the target in at most two, and so on: \mathcal K_N is the N-step controllable set, subject to the state and input constraints built into every step. For the hero's target [-0.25, 0.25]^2 and six steps the sets have 4, 6, 8, 8, 6, 10 and 10 vertices and areas 0.25, 1.75, 8.25, 19.92, 27.54, 34.03 and 38.09.

"At most" needs nesting. \mathcal K_j \subseteq \mathcal K_{j+1} holds here because the target box is itself control invariant: from any of its points some admissible input keeps the state inside, so a state that reaches it in j steps can wait there and reach it in j + 1. The numbers script checks it the way chapter A8 compares sets: every vertex of \mathcal K_j lies in \mathcal K_{j+1}. With a target that is not invariant the sets need not be nested, and "within N steps" has to be built as the union of the \mathcal K_j.

A minimum-step map. N_{\min}(x) = \min\{j : x \in \mathcal K_j\} is a crude distance to the target in control steps, not a Euclidean distance: two geometrically close states can need different numbers of steps because of velocity, saturation and the state constraints. On a grid of 161 by 121 states, 4088 of the 19 481 lie in the box but not in \mathcal K_6; the probe at (3.8, -1) needs 3 steps, (-2, 1) needs 2, and (3.8, 2.5) cannot reach the target in six, nor in any number, as chapter A10 explains. The hero shades N_{\min} and draws, for the probe, one admissible path that attains it: at each step the input of smallest magnitude that lands in the next inner set.

The horizon is a lever. The areas above grow with N and stop at 39.25, the area of \mathcal C_\infty, the largest set that can be kept inside the box for ever (chapter A10). Raise N in the hero: the controllable set fills \mathcal C_\infty at N = 7 for this target. Chapter A11 uses the same recursion with the terminal set as the target, and reads \mathcal K_N as the feasible set of an MPC with horizon N.

Part 5

Reachable against controllable

Easy to confuse. The forward reachable set \mathrm{Post}(\mathcal X_0) = A\mathcal X_0 \oplus B\,\mathcal U answers "where can I go?"; the predecessor answers "where can I start if I want to get there?". They are dual viewpoints, not the same operation, even though for the symmetric example of Part 3 one is the mirror image of the other through the origin. The difference shows on the whole box: one step from anywhere in \mathcal X reaches a hexagon of area 70, far outside the box's 48, because a cart at the edge moving outward leaves in one step whatever the input; the controllable sets, by contrast, never leave \mathcal X, since the intersection with it is part of every step.

Part 6

The code behind it

advanced_mpc_lmpc/polytopes.py · predecessor_scalar_input

def predecessor_scalar_input(S: HPolytope, A, B, umin, umax):
    """
    Exact H-representation of Pre(S) for x+=Ax+Bu and scalar u in [umin,umax]
    via Fourier-Motzkin elimination of u.
    """
    A = np.asarray(A, float); B = np.asarray(B, float).reshape(-1, 1)
    ax = S.H @ A
    bu = (S.H @ B).reshape(-1)
    c = S.h.copy()
    # input bounds as inequalities: u<=umax, -u<=-umin
    ax = np.vstack([ax, np.zeros((2, A.shape[1]))])
    bu = np.r_[bu, 1.0, -1.0]
    c = np.r_[c, umax, -umin]

    pos = np.where(bu > 1e-12)[0]
    neg = np.where(bu < -1e-12)[0]
    zer = np.where(np.abs(bu) <= 1e-12)[0]
    Hnew, hnew = [], []
    for i in zer:
        Hnew.append(ax[i]); hnew.append(c[i])
    for nidx in neg:
        for pidx in pos:
            # lower(nidx) <= upper(pidx)
            row = ax[pidx] / bu[pidx] - ax[nidx] / bu[nidx]
            rhs = c[pidx] / bu[pidx] - c[nidx] / bu[nidx]
            Hnew.append(row); hnew.append(rhs)
    return HPolytope(np.asarray(Hnew), np.asarray(hnew)).remove_redundancy()

The elimination of Part 3, line by line. ax and bu are the \alpha_i and \beta_i of the target rows, H_S A and H_S B; the two appended rows with a zero \alpha and \beta = \pm 1 are the input bounds u \le u_{\max} and -u \le -u_{\min}. The three index sets split the rows by the sign of \beta: zer rows do not involve u and pass through; every neg row (a lower bound) is paired with every pos row (an upper bound), and the pair's row and right-hand side are the two sides of the inequality divided by their \beta. remove_redundancy at the end is not optional: for the small box three of the nine pairs are redundant, and without the cleanup the row count would multiply at every step of a recursion.

advanced_mpc_lmpc/polytopes.py · n_step_controllable_sets

def n_step_controllable_sets(A, B, X: HPolytope, target: HPolytope,
                             umin, umax, N):
    """
    K_0 = target,
    K_{i+1} = X intersect Pre_U(K_i).
    """
    sets = [target.intersect(X)]
    for _ in range(N):
        pre = predecessor_scalar_input(sets[-1], A, B, umin, umax)
        sets.append(X.intersect(pre))
    return sets

The recursion of Part 4 in four lines: start from the target intersected with the state constraints, and at each step intersect the predecessor of the last set with \mathcal X again. The list returned holds every \mathcal K_j, which is what the hero shades and what chapter A11 plots against N.

advanced_mpc_lmpc/polytopes.py · reachable_set_scalar_input_2d

def reachable_set_scalar_input_2d(S: HPolytope, A, B, umin, umax):
    """
    One-step forward reachable set
        Post(S) = {A x + B u | x in S, u in [umin, umax]}
    for a 2-D state and scalar input.
    """
    A = np.asarray(A, float)
    B = np.asarray(B, float).reshape(-1)
    V = S.vertices_2d()
    pts = []
    for x in V:
        for u in (umin, umax):
            pts.append(A @ x + B * u)
    return HPolytope.from_vertices_2d(np.asarray(pts))

The forward set of Part 1: every vertex of \mathcal S mapped with both extreme inputs, then a hull. The extreme inputs suffice because Ax + Bu is affine in u, so the image of the segment \mathcal U is the segment between its endpoints' images, and a convex hull of segments is the hull of their endpoints.

Part 7

Common pitfalls

  1. "Reachable set equals predecessor set." No. \mathrm{Post}(\mathcal S) propagates forward from \mathcal S; \mathrm{Pre}_{\mathcal U}(\mathcal S) works backward into it. The mirror symmetry of the small example is an accident of symmetry.
  2. "One input works for the whole predecessor." No. The statement is \forall x\ \exists u; the witness depends on the state, and the hero's path picks a different one at every step.
  3. "\mathcal K_N is the states within N steps of the target in the plane." It is a distance in steps, not metres: velocity, saturation and the box decide it, which is why the shading has sloped bands.
  4. "The controllable sets always nest." Only when the target is control invariant. Otherwise a state that reaches the target in j steps may be unable to reach it in j + 1.
Part 8

Check your understanding

Try to answer each question before opening it.

1. Define the controlled predecessor precisely.

\mathrm{Pre}_{\mathcal U}(\mathcal S) = \{x \in \mathcal X : \exists u \in \mathcal U,\ Ax + Bu \in \mathcal S\}.

2. Why is predecessor computation a projection problem?

One first builds the set of state–input pairs (x, u) satisfying the target and admissibility conditions, then keeps the states for which at least one such input exists. Eliminating u is projection onto the x coordinates.

3. Explain the Minkowski interpretation of the predecessor.

The existence of some u \in \mathcal U with Ax + Bu \in \mathcal S is equivalent to Ax \in \mathcal S \oplus (-B\,\mathcal U). The preimage through A, intersected with \mathcal X, is the predecessor.

4. How does Fourier–Motzkin eliminate the input?

Every row is a lower or an upper bound on u (or does not involve it). An admissible u exists exactly when each lower bound is at most each upper bound, which gives one inequality in x per pair.

5. What does the N-step controllable set mean?

The states from which an admissible input sequence reaches the target within the recursion's horizon while respecting the constraints built into every step.

6. Why are the sets of the hero nested?

Because the target is control invariant: a state can reach it in j steps, then stay, so it also reaches it in j + 1.

7. What is a witness input, and how is one found?

An input that sends x into the target set, certifying x \in \mathrm{Pre}_{\mathcal U}(\mathcal S). For a scalar input the admissible ones form an interval, the intersection of the rows' lower and upper bounds with \mathcal U; a feasibility LP returns one of them.

8. Why is \mathrm{Post}(\mathcal X) larger than \mathcal X while every \mathcal K_j lies inside it?

Post is an image and may leave the box; the controllable recursion intersects with \mathcal X at every step, so it never leaves. The difference is the states that are inside the box now and outside it next step.

Part 9

Exercises

Each exercise has a hint and a solution; the code runs with the course package installed. Try first, then peek.

  1. Fourier–Motzkin by hand. From \alpha_1^\top x + 2u \le \gamma_1 and \alpha_2^\top x - u \le \gamma_2, eliminate u and derive one inequality in x alone.

    Hint

    The first row bounds u above, the second bounds it below.

    Solution

    Row 1: u \le (\gamma_1 - \alpha_1^\top x)/2. Row 2: u \ge \alpha_2^\top x - \gamma_2. A u exists iff the lower bound is below the upper: \alpha_2^\top x - \gamma_2 \le (\gamma_1 - \alpha_1^\top x)/2, that is (\alpha_1 + 2\alpha_2)^\top x \le \gamma_1 + 2\gamma_2. This is exactly one row of the predecessor_scalar_input loop, with \beta_1 = 2 and \beta_2 = -1.

  2. A predecessor with a weaker motor. Compute \mathrm{Pre}_{\mathcal U}(\mathcal S) for \mathcal S = [-1, 1] \times [-0.5, 0.5] and |u| \le 0.5. How many rows, and which vertices?

    Hint

    predecessor_scalar_input(S, A, B, -0.5, 0.5); intersect with the box to draw it.

    Solution

    Six rows after redundancy removal, and the vertices (-0.25, -1), (1.75, -1), (1.25, 0), (0.25, 1), (-1.75, 1), (-1.25, 0): a hexagon sheared along the position axis, since a cart at velocity v moves by v before the input can act.

    from advanced_mpc_lmpc.polytopes import HPolytope, predecessor_scalar_input
S = HPolytope.box([-1, -0.5], [1, 0.5])
P = predecessor_scalar_input(S, A, B, -0.5, 0.5)
print(len(P.h), X.intersect(P).vertices_2d())

  3. The input bound and the controllable set. Recompute \mathcal K_6 for |u| \le 0.5, 1 and 2 and compare the areas.

    Hint

    Set the hero's input bound; then n_step_controllable_sets with the three bounds.

    Solution

    Areas 21.45, 38.09 and 44.00. With less authority fewer states can be brought to the target in six steps; with twice the authority the set reaches most of the box, 44 of 48, leaving only the corners where the cart is at the position limit moving outward.

  4. The origin as the target. Replace the target box by the single point \{0\} and compute \mathcal K_1, \dots, \mathcal K_8 with |u| \le 1.

    Hint

    The target is HPolytope(np.vstack([np.eye(2), -np.eye(2)]), np.zeros(4)); \mathcal K_1 is a line segment of zero area.

    Solution

    Areas 0, 4.0, 15.6, 24.57, 31.75, 37.0, 39.25, 39.25: one step reaches the origin only from the segment of states with p + v + u/2 = 0 and v + u = 0, which has no area; from N = 7 on the set is all of \mathcal C_\infty. Chapter A11 uses this sequence as the feasible region of an MPC with the terminal constraint x_N = 0.

  5. Build it: the predecessor by projection. Implement the predecessor yourself: stack the rows of the lifted polytope in (x, u), split them by the sign of the u-coefficient, form the pairwise rows, remove the redundant ones. Compare with the package on the small box.

    Hint

    G = np.c_[S.H @ A, S.H @ B] plus the two bound rows [0, 0, 1] and [0, 0, -1]; a pair's row is G[p, :2] / G[p, 2] - G[n, :2] / G[n, 2].

    Solution

    Nine pairwise rows, six after redundancy removal, and approximately_equal confirms the set matches the package's.

    G = np.vstack([np.c_[S.H @ A, S.H @ B], [[0, 0, 1], [0, 0, -1]]]); g = np.r_[S.h, 1.0, 1.0]
pos = [i for i in range(len(g)) if G[i, 2] > 1e-12]; neg = [i for i in range(len(g)) if G[i, 2] < -1e-12]
rows = [(G[p, :2] / G[p, 2] - G[n, :2] / G[n, 2], g[p] / G[p, 2] - g[n] / G[n, 2]) for n in neg for p in pos]
mine = HPolytope(np.array([r for r, _ in rows]), np.array([b for _, b in rows])).remove_redundancy()
print(len(rows), len(mine.h), mine.approximately_equal(predecessor_scalar_input(S, A, B, -1, 1)))   # 9 6 True

  6. A target that is not invariant. Take the target \mathcal S = \{x : p \in [2, 3],\ v \in [1, 2]\}, a box of states moving right near the edge. Are the controllable sets nested? Why not?

    Hint

    Check whether every vertex of \mathcal K_0 lies in \mathcal K_1; think about where a cart at (3, 2) is after one step.

    Solution

    No. From (3, 2) the next position is at least 3 + 2 - 0.5 = 4.5, outside the box, so the target's corner has no admissible successor at all, let alone one inside the target. \mathcal K_1 does not contain \mathcal K_0, "reaches the target in at most j steps" and "reaches it in exactly j steps" come apart, and a state in \mathcal K_0 can be doomed. Chapter A10 names the property the target lacks.

Part 10

The chapter on one page

  1. Forward: \mathrm{Post}(\mathcal S) = A\mathcal S \oplus B\,\mathcal U, the hull of the vertices mapped with the extreme inputs; it can leave the box.
  2. Backward: \mathrm{Pre}_{\mathcal U}(\mathcal S) = \{x \in \mathcal X : \exists u \in \mathcal U,\ Ax + Bu \in \mathcal S\}, a projection of the lifted set, equivalently A^{-1}(\mathcal S \oplus (-B\,\mathcal U)).
  3. Fourier–Motzkin: pair every lower bound on u with every upper bound; 4 target rows and 2 bounds give 9 rows, 6 kept.
  4. A witness: at (-0.65, 0.45) the admissible inputs into the small box are [-0.4, -0.1].
  5. Controllable sets: \mathcal K_{j+1} = \mathcal X \cap \mathrm{Pre}_{\mathcal U}(\mathcal K_j); nested when the target is control invariant; areas 0.25 to 38.09 over six steps, 39.25 at N = 7.
  6. N_{\min} is a distance in steps, not metres; 4088 of 19 481 grid states cannot reach the target in six.

The vocabulary, in one table

Word Meaning
Post, Pre One-step forward reachable set; controlled predecessor.
Fourier–Motzkin Eliminating a variable by pairing its lower and upper bounds.
Witness input An input that sends a state into the target, certifying membership in Pre.
\mathcal K_N The N-step controllable set to a target.
N_{\min}(x) The fewest steps in which x can reach the target.
Nested \mathcal K_j \subseteq \mathcal K_{j+1}; guaranteed by a control-invariant target.

Scope. Exact reachability for a 2-D linear system with a scalar input and polytopic constraints, nominal and deterministic. Vector inputs need a general projection; disturbances need the robust predecessor, which subtracts the disturbance set first.
