Positive and control invariance

A state that satisfies the constraints now may have no admissible future: a cart near the wall at speed will cross it next step whatever the motor does. The states that can be kept inside the constraints for ever form a set, and the question splits in two according to who chooses the input. With one fixed law, the set is positively invariant; with the freedom to choose at every state, it is control invariant. Both are the fixed point of an iteration that removes doomed states one step at a time, and both run live below, where any state can be probed for its safest move.

Part 1

Positive invariance: a fixed law, and where it is admissible

Positive invariance. For the autonomous system x^+ = A_{\mathrm{cl}} x, a set \Omega is positively invariant if

\boxed{x \in \Omega \ \Longrightarrow\ A_{\mathrm{cl}} x \in \Omega}, \qquad \text{equivalently } A_{\mathrm{cl}} \Omega \subseteq \Omega :

once a trajectory enters, the fixed dynamics keep it there for ever. The autonomous system of this course is the cart under the LQR law of chapter A7, u = -Kx with K = (0.7396, 1.2604), so A_{\mathrm{cl}} = A - BK with eigenvalues 0.185 \pm 0.274\,i: the loop is stable, every trajectory converges, and yet not every state can be left to it.

A subtle but essential point: input constraints under a fixed feedback. A state may be inside \mathcal X while the feedback demands more than the actuator can give. At the corner (4, 3), a cart at the position limit moving fast towards it, the LQR asks for -Kx = -6.74, nearly seven times the bound; at (-4, 3), the same speed moving away from the near wall, it asks for -0.82, which is fine. The admissible closed-loop state set is therefore not \mathcal X but

\boxed{\mathcal X_K = \{x \in \mathcal X : u_{\min} \le -Kx \le u_{\max}\}},

the box with two corners cut off by the half-spaces -Kx \le u_{\max} and Kx \le -u_{\min}: six vertices, area 12.66 of the box's 48, drawn in purple in the hero's second mode.

What is an invariant set?

In plain words: a region the system cannot leave. Positively invariant: it cannot leave under one fixed controller. Control invariant: it cannot be forced to leave, because at every point some admissible input keeps it in.

More precisely: \Omega is positively invariant for x^+ = A_{\mathrm{cl}} x if A_{\mathrm{cl}} \Omega \subseteq \Omega; \mathcal C is control invariant for x^+ = Ax + Bu, u \in \mathcal U, if \forall x \in \mathcal C\ \exists u \in \mathcal U : Ax + Bu \in \mathcal C. The maximal such subsets of a constraint set are the fixed points of \Omega_{j+1} = \mathcal S \cap A_{\mathrm{cl}}^{-1}(\Omega_j) and \mathcal C_{j+1} = \mathcal X \cap \mathrm{Pre}_{\mathcal U}(\mathcal C_j).

Part 2

The maximal positively invariant set

The maximal positively invariant subset of a constraint set \mathcal S is \mathcal O_\infty(\mathcal S) = \bigcap_{k=0}^{\infty} A_{\mathrm{cl}}^{-k} \mathcal S: in \mathcal S now, after one step, after two, for ever. The practical fixed-point iteration [3] is

\Omega_0 = \mathcal S, \qquad \boxed{\Omega_{j+1} = \mathcal S \cap A_{\mathrm{cl}}^{-1}(\Omega_j)}, \qquad \text{stop when } \Omega_{j+1} = \Omega_j ,

with the preimage of chapter A8, rows multiplied by A_{\mathrm{cl}}. For the LQR inside \mathcal S = \mathcal X_K the iteration stops after 2 steps with \mathcal O_\infty of 4 vertices, the parallelogram (\pm 2.404, \mp 2.204), (\pm 2.204, \mp 0.5) of area 7.31: \Omega_1 already has it, and \Omega_2 = \Omega_1 confirms it.

Why the iteration removes states. \Omega_0 = \mathcal X_K is every state that is admissible now. \Omega_1 removes those that leave the admissible set after one step; \Omega_2 those that survive one step and fail later; and so on until nothing more needs removing. The algorithm converts a one-step constraint set into an infinite-time safe set for that closed-loop law. Why is \mathcal O_\infty so much smaller than \mathcal X_K? From the sloped edge of \mathcal X_K, one LQR step lands outside \mathcal X_K: the input is admissible now but not next time. Invariance is a statement about every future step, and the fixed point enforces it. Select the fixed-LQR mode in the hero, drag j, and click a state in the purple strip but outside the blue parallelogram: the four black LQR steps leave the strip.

The checks at the vertices. Because \mathcal O_\infty is convex and A_{\mathrm{cl}} linear, it suffices to check its vertices: each maps back into \mathcal O_\infty, and the LQR input at each is exactly \pm 1, the bound. The set is as large as the motor allows. Chapter A11 uses exactly this set as the terminal set of a stabilising MPC.

Part 3

Control invariance: the quantifier

Back to x^+ = Ax + Bu. A set \mathcal C is control invariant if

\boxed{\forall x \in \mathcal C,\ \exists u \in \mathcal U \ \text{such that}\ Ax + Bu \in \mathcal C}.

The order of the quantifiers matters enormously: for each state in the set, at least one admissible input keeps the next state in the set, and the input may differ at every state. A fixed controller commits to one action-selection rule; control invariance keeps the freedom to choose state by state, so a control-invariant set can be larger than the invariant set of any one feedback law.

The maximal control-invariant subset of \mathcal X is the fixed point of

\mathcal C_0 = \mathcal X, \qquad \boxed{\mathcal C_{j+1} = \mathcal X \cap \mathrm{Pre}_{\mathcal U}(\mathcal C_j)} :

keep the states that satisfy the constraints now and have an admissible input into the current candidate; repeat, with the Fourier–Motzkin predecessor of chapter A9. For the cart with |u| \le 1 it converges in 4 iterations to a 10-vertex set \mathcal C_\infty of area 39.25, through candidates of 4, 6, 8, 10, 10 vertices and areas 48, 41.75, 39.5, 39.25, 39.25: the first step cuts the two corners where position and velocity have the same sign, the next ones shave the cuts until a cart can always be stopped before the wall. Every vertex of the LQR's \mathcal O_\infty (area 7.31) lies inside it: freedom to choose enlarges the safe set 5.4-fold.

A control-invariant set is a one-step feasibility certificate that repeats. If x \in \mathcal C_\infty, some admissible u gives x^+ \in \mathcal C_\infty; since the next state is in the same set, the argument repeats, and the constraints can be maintained indefinitely. The qualification: under the nominal model used to compute the set.

Part 4

The geometry of safety: four states, and a safe action

Target reachability and invariance are different concepts. A finite-step controllable set of chapter A9 answers "can I reach the target within so many steps?"; an invariant set answers "can I remain admissible for ever?". A state can be safe indefinitely but far from the target, able to reach the target quickly, immediately admissible but doomed to violate a constraint later, or outside the safe kernel while satisfying every current constraint. Set-based analysis carries more information than checking the current state against a box.

Constraint boundaries are not all equally dangerous. The states (3.8, -1) and (3.8, 2.5) are equally close to the position boundary p = 4. The first is moving inward; the second is rushing at the wall. The sets know. The table is recomputed from the hero's settings; the last column is where the position can be next step, p + v \pm 0.5 u_{\max}.

All four satisfy the box constraints now. Two have no admissible future at all: (3.8, 2.5) will cross p = 4 next step whatever u is, since p^+ = 3.8 + 2.5 + 0.5u \ge 5.8, and (-3.5, -2.2) likewise at the other wall. None is safe under the LQR law, whose admissible region is the thin parallelogram.

Computing a safe action at a state. Control invariance says an admissible action exists; it does not say which. One simple policy for x \in \mathcal C_\infty:

\min_u\ u^2 \quad \text{subject to}\quad Ax + Bu \in \mathcal C_\infty, \quad u_{\min} \le u \le u_{\max},

the smallest input that keeps the next state inside. For a scalar input the constraints cut an interval out of [u_{\min}, u_{\max}], the witness interval of chapter A9, and the answer is 0 projected onto it. At x = (3, 0.8) the feasible interval is [-1, -0.0667], so the minimum-effort safe input is u = -0.0667, sending the state to (3.767, 0.733), still inside. The invariant set supplies the guarantee; the secondary objective chooses among safe actions. Click (3, 0.8) in the hero to see it.

Part 5

What membership certifies

A nominal, repeatable guarantee, nothing more. x \in \mathcal C_\infty certifies that, under the model used to compute the set, an admissible input exists that keeps the next state in the same set, and hence that the constraints can be kept for ever. It certifies nothing about disturbances, model error or a state that is estimated rather than measured: with any of these, nominal invariance alone is not robustness, and the set must be built with the uncertainty inside it. It also says nothing about reaching a target or about cost; that is what chapter A11 adds, with a terminal cost on top of a terminal set.

What the sets become later. \mathcal O_\infty is the terminal set \mathcal X_f of chapter A11: a plan that ends inside it can be continued by the LQR for ever, admissibly. \mathcal C_\infty is the limit of the MPC feasible sets as the horizon grows, and the set a plain MPC without terminal ingredients must stay inside to remain feasible (lab B6). Chapter A12 replaces both by a set learned from data, the convex hull of states a successful run visited, and proves it control invariant with the same quantifier.

Part 6

The code behind it

advanced_mpc_lmpc/polytopes.py · closed_loop_admissible_set_scalar_input

def closed_loop_admissible_set_scalar_input(X: HPolytope, K, umin, umax):
    """
    States in X for which u=-Kx respects scalar input bounds.
    """
    K = np.asarray(K, float).reshape(1, -1)
    Hu = np.vstack([-K, K])
    hu = np.array([umax, -umin], float)
    return X.intersect(HPolytope(Hu, hu))

The two half-spaces of Part 1: -Kx \le u_{\max} is the row -K with right-hand side u_{\max}, and -Kx \ge u_{\min} is the row K with right-hand side -u_{\min}. Intersecting them with the box gives \mathcal X_K; for the canonical gain the two rows cut the corners (4, 3) and (-4, -3).

advanced_mpc_lmpc/polytopes.py · maximal_invariant

def maximal_invariant(A, X: HPolytope, max_iter=100, tol=1e-7):
    """Maximal positively invariant subset of X for autonomous x+=Ax."""
    Omega = X.remove_redundancy()
    history = [Omega]
    for _ in range(max_iter):
        nxt = X.intersect(linear_preimage(Omega, A))
        history.append(nxt)
        if nxt.approximately_equal(Omega, tol):
            return nxt, history
        Omega = nxt
    return Omega, history

The iteration of Part 2. linear_preimage(Omega, A) multiplies the rows by A_{\mathrm{cl}} and keeps the right-hand sides; X.intersect(...) stacks them with the constraint rows and removes the redundant ones; approximately_equal is the vertex-based set comparison of chapter A8, which is what makes the stopping test reliable when the rows of two equal sets differ. The history is returned so that the hero can show every iterate.

advanced_mpc_lmpc/polytopes.py · maximal_control_invariant

def maximal_control_invariant(A, B, X: HPolytope, umin, umax, max_iter=100, tol=1e-7):
    """Maximal control-invariant subset of X for scalar constrained input."""
    C = X.remove_redundancy()
    history = [C]
    for _ in range(max_iter):
        pre = predecessor_scalar_input(C, A, B, umin, umax)
        nxt = X.intersect(pre)
        history.append(nxt)
        if nxt.approximately_equal(C, tol):
            return nxt, history
        C = nxt
    return C, history

The same loop with the controlled predecessor of chapter A9 in place of the preimage. The quantifier lives inside predecessor_scalar_input: Fourier–Motzkin elimination keeps a state exactly when some u in the bounds sends it into the candidate, and the state-dependence of that u is what the pairwise rows encode. Four passes for the canonical cart, seven with half the input authority.

Part 7

Common pitfalls

  1. "Control invariance means one input works for the whole set." No. The statement is \forall x \in \mathcal C,\ \exists u; the input may depend on the state. Exercise 3 shows that no single input works even for two states.
  2. "Satisfying constraints now implies future safety." No. (3.8, 2.5) lies in \mathcal X but outside \mathcal C_\infty: admissible now, with no admissible strategy that preserves the constraints for ever.
  3. "Stable feedback automatically respects constraints." No. A stabilising K can command u = -Kx beyond the actuator limits; the fixed-controller invariant set must be computed inside \mathcal X_K, not \mathcal X.
  4. "An invariant set is automatically robust." Not unless uncertainty is built into its construction. The sets here are nominal.
  5. "The fixed point is reached when the row counts agree." Two representations of the same set can have different rows; the stopping test compares vertices.
Part 8

Check your understanding

Try to answer each question before opening it.

1. Define positive invariance.

For x^+ = A_{\mathrm{cl}} x, \Omega is positively invariant if x \in \Omega implies A_{\mathrm{cl}} x \in \Omega.

2. Define control invariance and state the quantifiers.

For every state in the set there exists at least one admissible input sending the next state back into the set: \forall x \in \mathcal C,\ \exists u \in \mathcal U : Ax + Bu \in \mathcal C.

3. Why must input constraints be included when computing a closed-loop invariant set?

A trajectory may stay inside the state constraints while the feedback demands an inadmissible actuator command, as the LQR does at (4, 3). The admissible closed-loop set must enforce both.

4. Why is a maximal control-invariant set usually larger than the invariant set of one fixed controller?

Control invariance may choose a different admissible input at every state; a fixed controller commits to one law and has less freedom. Here the ratio of areas is 5.4.

5. What does one step of the iteration \Omega_{j+1} = \mathcal S \cap A_{\mathrm{cl}}^{-1}(\Omega_j) remove?

The states of \Omega_j whose next state under the fixed law leaves \Omega_j: after j + 1 steps, the states that stay admissible for j + 1 steps.

6. What does membership in a control-invariant set certify?

Under the nominal model and the stated constraints, that an admissible input exists keeping the next state in the same set, so the argument repeats indefinitely. Nothing about disturbances, targets or cost.

7. How is a safe action chosen once a state is known to be in \mathcal C_\infty?

By any secondary objective over the witness interval, the admissible inputs whose successor lies in \mathcal C_\infty; the least-effort choice is zero projected onto that interval.

8. How do the two sets reappear in MPC?

\mathcal O_\infty becomes the terminal set, from which a local controller can continue admissibly for ever; \mathcal C_\infty is the largest region any MPC can be recursively feasible on.

Part 9

Exercises

Each exercise has a hint and a solution; the code runs with the course package installed. Try first, then peek.

  1. Fixed feedback. For u = -Kx with |u| \le 1, derive the two half-space inequalities defining the input-admissible state region, and find which corners of the box they cut.

    Hint

    Write |{-Kx}| \le 1 as two linear inequalities; evaluate -Kx at the four corners.

    Solution

    -Kx \le 1 and Kx \le 1: rows -K and K with right-hand sides 1 and 1. For K = (0.7396, 1.2604) they are the two sloped edges of \mathcal X_K; at (4, 3) and (-4, -3) the law asks for \mp 6.74, so those corners are cut, while at (-4, 3) and (4, -3) it asks for \mp 0.82 and they stay. This is closed_loop_admissible_set_scalar_input.

  2. Invariant-set recursion. Starting with \Omega_0 = \mathcal S, explain why \Omega_1 = \mathcal S \cap A^{-1}(\mathcal S) contains exactly the states satisfying the constraint at times 0 and 1, and extend the interpretation to \Omega_2.

    Hint

    Unfold A^{-1}(\Omega_1).

    Solution

    x \in \mathcal S is the constraint at time 0; x \in A^{-1}(\mathcal S) means Ax \in \mathcal S, the constraint at time 1. Their intersection is exactly "satisfied at 0 and 1". Then \Omega_2 = \mathcal S \cap A^{-1}(\Omega_1) = \mathcal S \cap A^{-1}(\mathcal S) \cap A^{-2}(\mathcal S): satisfied at 0, 1 and 2. In general \Omega_j = \bigcap_{k=0}^{j} A^{-k}\mathcal S, and the fixed point is the infinite intersection \mathcal O_\infty. For the LQR, \Omega_1 already removes the corners of \mathcal X_K and \Omega_2 = \Omega_1.

  3. Quantifiers. Explain the difference between \forall x \in \mathcal C,\ \exists u \in \mathcal U and \exists u \in \mathcal U,\ \forall x \in \mathcal C. Which defines control invariance? Show with two states of \mathcal C_\infty that the second fails.

    Hint

    In which one may u depend on x? Try (3.8, 0.5) and (-3.8, -0.5).

    Solution

    In \forall x\ \exists u, the input is chosen after the state is known and may differ from state to state: that is control invariance, and what a feedback law or an MPC does. In \exists u\ \forall x, one single input must work for every state in the set at once, a far stronger and rarely true statement: (3.8, 0.5) needs p^+ = 4.3 + 0.5u \le 4, so u \le -0.6, and (-3.8, -0.5) needs p^+ = -4.3 + 0.5u \ge -4, so u \ge 0.6. No single u does both. The second statement implies the first, never the reverse.

  4. A weaker motor. Change the input limit from |u| \le 1 to |u| \le 0.5 and to |u| \le 0.4. Recompute \mathcal K_6, \mathcal C_\infty and the fixed-LQR invariant set, and explain the geometric changes.

    Hint

    Set the hero's input bound to 0.5 and 0.4 and look at both modes; then run the code.

    Solution

    With less authority everything shrinks. At |u| \le 0.5: \mathcal K_6 falls from area 38.09 to 21.45, since fewer states can be brought to the target in six steps; \mathcal C_\infty from 39.25 to 30.29, now with 14 vertices after 7 iterations, because a cart moving at speed v needs v / 0.5 steps to stop and the position it covers meanwhile must fit in the box, which cuts the corners deeper; and the LQR's \mathcal O_\infty collapses from 7.31 to 1.83, since \mathcal X_K = \{|{-Kx}| \le 0.5\} is a strip only half as wide. At |u| \le 0.4 the three areas are 17.38, 27.07 and 1.17. The fixed law is punished most, because it cannot trade a smaller input for a longer manoeuvre.

area = lambda P: ConvexHull(P.vertices_2d()).volume
for um in (1.0, 0.5, 0.4):

  5. A gentler gain. Recompute K with R = 2 instead of 0.2, and the invariant set of the new law with |u| \le 1. Why is it larger, and what is the price?

    Hint

    dlqr(A, B, Q, [[2.0]]); compare the spectral radius and the area of \mathcal X_K.

    Solution

    K = (0.3858, 0.8952), spectral radius 0.546 instead of 0.331: a gentler, slower loop. It saturates less often, so \mathcal X_K has area 17.87 and its invariant subset has six vertices and area 17.87, nearly all of it, in two iterations, against 7.31 for the course's gain. The price is a slower local loop, which chapter A11 turns into a trade-off between the size of the terminal set and the speed inside it. Set R = 2 in the hero's second mode to see it.

  6. Build it: the control-invariant iteration. Write the fixed-point loop yourself with predecessor_scalar_input and intersect, stop when the set no longer changes, and compare with maximal_control_invariant.

Part 10

The chapter on one page

  1. Positive invariance, x \in \Omega \Rightarrow A_{\mathrm{cl}} x \in \Omega, is about one fixed law, and must be computed inside \mathcal X_K, where the law's input is admissible: area 12.66, two corners cut.
  2. \mathcal O_\infty is the fixed point of \Omega_{j+1} = \mathcal X_K \cap A_{\mathrm{cl}}^{-1}(\Omega_j): a parallelogram of area 7.31 in two iterations, the LQR input at its vertices exactly \pm 1.
  3. Control invariance, \forall x\ \exists u, keeps the freedom to choose state by state; \mathcal C_\infty is the fixed point of \mathcal C_{j+1} = \mathcal X \cap \mathrm{Pre}_{\mathcal U}(\mathcal C_j): ten vertices, area 39.25, four iterations, 5.4 times \mathcal O_\infty.
  4. Doomed states satisfy the box now and cannot stay in it: (3.8, 2.5) and (-3.5, -2.2).
  5. A safe action is any input in the witness interval; the least effort at (3, 0.8) is -0.067.
  6. What membership certifies: a nominal, repeatable one-step guarantee, nothing about disturbances.

The vocabulary, in one table

Word Meaning
Positively invariant Under a fixed law, every point of the set stays in the set.
Control invariant For every point, some admissible input keeps the next state in the set.
\mathcal X_K The states where the fixed law's input is admissible.
\mathcal O_\infty, \mathcal C_\infty The maximal positively invariant set of a law; the maximal control-invariant set.
Fixed-point iteration Remove the states that leave the candidate; stop when nothing changes.
Doomed state In \mathcal X but not in \mathcal C_\infty.
Witness interval The inputs that keep the next state in the set; a safe action is any of them.

Scope. Nominal invariance for a 2-D linear system with a scalar input and polytopic constraints, exact and drawn. Robust invariance, which subtracts a disturbance set at every step, and invariant sets for nonlinear systems are outside the scope; lab B6 says where they enter.
