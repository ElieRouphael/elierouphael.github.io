Advanced MPC and Learning MPC · Chapter 09 of 09

Capstone: one design, end to end

Chapters 01 to 08 built the tools one at a time: the finite-horizon problem as a quadratic program, invariant and controllable sets, terminal ingredients and stability, Learning MPC, and the dynamic-programming view that connects them. This capstone applies them together to the constrained double integrator of chapters 02 and 08 and checks every guarantee numerically: LQR terminal ingredients verified at the vertices of the terminal set, recursive feasibility and Lyapunov decrease from every feasible state of a grid, the same controller stripped of its terminal ingredients, and Learning MPC started from a deliberately poor trajectory. Throughout, keep apart a guarantee, proved for every state of a stated set, and an observation, which holds for the cases that were simulated. The checks below are built to tell the two apart, including when the numerical solver, not the controller, is the weak link.

Part 1

Model, constraints and LQR terminal ingredients

The state x = (p, v) is position and velocity sampled with period 1 under a piecewise-constant acceleration u; constraints and stage cost are those of chapters 02 and 08. The MPC problem at the current state is

J_N^\star(x) = \min_{u_0, \ldots, u_{N-1}}\ \sum_{k=0}^{N-1} q(x_k, u_k) + V_f(x_N) \quad \text{s.t.} \quad x_0 = x,\ x_{k+1} = Ax_k + Bu_k,\ x_k \in \mathcal X\ (k = 1, \ldots, N),\ u_k \in \mathcal U,\ x_N \in \mathcal X_f,

and \mathcal X_N is the set of states where it is feasible. With a local controller u = -Kx, chapter 03 requires three things of the terminal ingredients:

  1. \mathcal X_f \subseteq \mathcal X and -Kx \in \mathcal U for all x \in \mathcal X_f.
  2. (A - BK)x \in \mathcal X_f for all x \in \mathcal X_f: positive invariance.
  3. V_f((A - BK)x) - V_f(x) \le -q(x, -Kx) for all x \in \mathcal X_f: the terminal decrease.

The LQR provides all three. With P the stabilising solution of the DARE and K = (R + B^\top PB)^{-1}B^\top PA, the terminal cost V_f = x^\top Px satisfies condition 3 with equality for every x, because the DARE is equivalent to A_K^\top PA_K - P = -(Q + K^\top RK) with A_K = A - BK. For conditions 1 and 2 take \mathcal X_f = \mathcal O_\infty, the maximal positively invariant set of x^+ = A_Kx inside \mathcal X_K = \{x \in \mathcal X : -Kx \in \mathcal U\}, from chapter 02's recursion \mathcal O_0 = \mathcal X_K, \mathcal O_{i+1} = \mathcal X_K \cap \{x : A_Kx \in \mathcal O_i\} until it stops. Conditions 1 and 2 at the vertices imply them on all of \mathcal X_f, since the set is convex and the maps linear; condition 3 is an identity in x.

Part 2

Feasible sets of MPC with terminal ingredients

The feasible set of the MPC problem is the N-step controllable set to \mathcal X_f (chapter 02):

\mathcal K_0 = \mathcal X_f, \qquad \mathcal K_{i+1} = \mathcal X \cap \operatorname{Pre}(\mathcal K_i), \qquad \operatorname{Pre}(\mathcal S) = \{x : \exists u \in \mathcal U,\ Ax + Bu \in \mathcal S\}, \qquad \mathcal X_N = \mathcal K_N.

Because \mathcal X_f is control invariant, \mathcal X_f \subseteq \operatorname{Pre}(\mathcal X_f), and induction gives the nested sequence \mathcal X_f = \mathcal K_0 \subseteq \mathcal K_1 \subseteq \cdots \subseteq \mathcal C_\infty. Each \mathcal K_i is control invariant as well: from x \in \mathcal K_i some admissible input reaches \mathcal K_{i-1} \subseteq \mathcal K_i. This set-level statement is recursive feasibility; exercise B.3 proves it for input sequences.

Part 3

Recursive feasibility and stability on a grid

What the theory promises

For every initial state in \mathcal X_N (chapter 03; exercises B.3 and B.4): the MPC problem remains feasible at every step; the value decreases, J_N^\star(x^+) - J_N^\star(x) \le -q(x, \kappa_N(x)) with \kappa_N(x) = u_0^\star(x) the MPC law; and J_N^\star(x) \ge \lambda_{\min}(Q)\|x\|^2 everywhere while J_N^\star(x) \le V_f(x) \le \lambda_{\max}(P)\|x\|^2 on \mathcal X_f. These are the three Lyapunov conditions, so the origin is exponentially stable with region of attraction \mathcal X_N. The LQR ingredients add one fact: from x \in \mathcal X_f the LQR plan is admissible and optimal, because P is a fixed point of the Riccati recursion, hence J_N^\star = V_f and \kappa_N = -Kx on \mathcal X_f: inside the terminal set, the MPC is the LQR.

What is checked. Each point of a grid with spacing 0.5 over \mathcal X, 221 states, that is feasible for N \in \{2, 3, 5\} starts a 40-step closed loop. The demo at the top of the page records feasibility, the decrease residual J_N^\star(x^+) - J_N^\star(x) + q(x, u) (theory: at most zero) and the entry into \mathcal X_f, for any horizon from 1 to 6 and for either design.

An auditable solver. The course's QP wrapper uses SciPy's SLSQP, which can report failure on degenerate but feasible QPs (at boundary states of \mathcal X_N, where the feasible input sequences have an empty interior) and can stop early near the origin. A failure flag is not an infeasibility certificate. The notebook therefore calls SLSQP first and, on failure, solves a linear program for the smallest s \ge 0 such that some input sequence satisfies all constraints relaxed by s: s = 0 certifies feasibility, s > 0 infeasibility; a feasible QP is then solved exactly as a least-distance problem by non-negative least squares. One QP in the whole grid needed the fallback, at x = (4, 0.5), a vertex of \mathcal C_\infty reached from (1, 2.5) with N = 5: the position is at its bound with the velocity pointing outward, so p_1 = 4.5 + 0.5u_0 \le 4 forces u_0 = -1, the feasible input sequences lie in a hyperplane, and SLSQP declared the constraints incompatible. The LP certified feasibility and the exact solver returned a plan. A solver artefact, not a counterexample to recursive feasibility. This page uses the same LP to decide feasibility and an interior-point method for the QPs, which handles the degenerate vertex without a fallback; its residuals are around 10^{-11}.

Part 4

Removing the terminal ingredients

The textbook variant drops both ingredients, V_f = 0 and no terminal set. Its feasible set is \mathcal K_N(\mathcal X), the states that can be kept in \mathcal X for N steps (the recursion of Part 2 started from \mathcal K_0 = \mathcal X). This sequence shrinks towards \mathcal C_\infty, and for short horizons it contains doomed states: the QP is feasible now, yet every admissible input sequence leaves \mathcal X eventually. None of the proofs of Part 3 applies. Costs are compared with J_\infty^\star(x_0), sandwiched between J_{12}^\star of the terminal design, an upper bound because its plan followed by the LQR is admissible, and J_{30}^0 of the plain problem, a lower bound because it drops the tail; the two differ by at most 6.9 \times 10^{-9} on the grid.

The notebook's grid. N = 1 fails badly: u_0 = 0 minimises q(x_0, u_0) whenever Ax \in \mathcal X, so the controller coasts until a bound forces it to brake, then brakes as little as possible; states (p, 0) are equilibria, 76 feasible starts never converge, and from 100 of the 177 starts in \mathcal C_\infty it coasts into a state where one braking step is not enough, as from (-1, 2) to (3, 2), where p_1 = 5 + 0.5u \le 4 would need u \le -2; all 14 doomed starts fail too. N = 2 accepts the two doomed grid starts (0, \pm 3), which lose feasibility; every start in \mathcal C_\infty converges, but at up to 2.15\, J_\infty^\star, and 24 starts pay more than 20 percent extra; from x_S = (-3.5, 2.5) the controller keeps its speed too long, overshoots to p = 2 and spirals back, at 1.69\, J_\infty^\star, where the terminal design with the same N has a worst ratio of 1.0010. From N = 3 on nothing visibly goes wrong: \mathcal K_3(\mathcal X) = \mathcal C_\infty, and the worst costs are 1.0945, 1.0032 and 1.0000 times J_\infty^\star for N = 3, 4, 5.

What is lost is the certificate. With V_f = 0 the principle of optimality gives J_N^0(x) = q(x, u_0^\star) + J_{N-1}^0(x^+), hence

J_N^0(x^+) - J_N^0(x) + q(x, u_0^\star) = J_N^0(x^+) - J_{N-1}^0(x^+) \ \ge\ 0,

because with a zero terminal cost a longer horizon can only add cost (chapter 08). The decrease inequality of Part 3 holds with the wrong sign: in the notebook it fails at all 2060 (N = 2) and 1352 (N = 3) steps away from the origin, and the value even increases at 118 and 42 of them. Proofs for MPC without terminal ingredients exist, but they need a long enough horizon and controllability assumptions (Part 8). The terminal ingredients give the guarantee at every horizon.

Part 5

Learning MPC from a poor first trajectory

Learning MPC (chapter 05) replaces the designed terminal ingredients by data. The states of every trajectory that reached the target become rows of a matrix S, their realised costs-to-go a vector \mathbf J, and iteration j solves

\min_{u_0, \ldots, u_{N-1},\, \lambda}\ \sum_{k=0}^{N-1} q(x_k, u_k) + \mathbf J^\top\lambda \quad \text{s.t.} \quad x_0 = x,\ x_{k+1} = Ax_k + Bu_k,\ x_k \in \mathcal X,\ u_k \in \mathcal U,\ x_N = S^\top\lambda,\ \mathbf 1^\top\lambda = 1,\ \lambda \ge 0.

The terminal set is the convex safe set CS^j, the hull of the stored states, and the terminal cost the barycentric value V_c^j (exercises B.5 and B.6). For linear dynamics, convex constraints and a convex stage cost, chapter 05 shows that every iteration is recursively feasible and converges to the target; that J^{j+1}(x_S) \le J^j(x_S), because the previous trajectory remains a feasible candidate; and, since each iteration is admissible, J^j(x_S) \ge J_\infty^\star(x_S). The costs therefore converge, but convergence to J_\infty^\star is not among the guarantees.

Setup. x_S = (-3.5, 2.5); the first trajectory is the plain N = 2 closed loop of Part 4, feasible but at 1.69\, J_\infty^\star. Stored trajectories must end exactly at the target, so each run stops once \|x\| \le 10^{-3} and is completed by the two deadbeat inputs [u_0; u_1] = -[AB\ \ B]^{-1}A^2x. LMPC then runs 10 iterations for each N \in \{2, 3, 4\} with all stored data.

The guarantees say nothing about the limit; chapter 05 already warned that feasibility alone gives no optimality guarantee. Part 6

Derivations to reproduce

Each exercise is a derivation that Parts 1 to 5 relied on. Work it out before opening the answer.

  1. B.1, the condensed QP. Eliminate the states and write the MPC problem as \min_U \tfrac12 U^\top HU + f^\top U + c subject to GU \le w. Show that H \succ 0 and say which quantities depend on the current state.
    Answer

    Stack \mathbf x = (x_1, \ldots, x_N) and U = (u_0, \ldots, u_{N-1}); the dynamics give \mathbf x = S_x x_0 + S_u U with the prediction matrices of chapter 01. With \bar Q = \operatorname{blkdiag}(Q, \ldots, Q, P) and \bar R = \operatorname{blkdiag}(R, \ldots, R) the cost is x_0^\top Qx_0 + \mathbf x^\top\bar Q\mathbf x + U^\top\bar RU, and substitution gives H = 2(S_u^\top\bar QS_u + \bar R), f = 2S_u^\top\bar QS_xx_0, c = x_0^\top Qx_0 + x_0^\top S_x^\top\bar QS_xx_0. The constraints stack the state bounds \pm S_u U \le \pm(\ldots) - S_xx_0, the input bounds \pm U \le \ldots, and the terminal rows H_f S_u^{(N)} U \le h_f - H_f A^N x_0. H \succ 0 because \bar R \succ 0 and S_u^\top\bar QS_u \succeq 0, so a feasible QP has a unique minimiser. H and G are fixed, f and w are affine in x_0, c quadratic: the MPC problem is a multiparametric QP, which is why the MPC law is piecewise affine (explicit MPC). The notebook checks the formulas against 1000 random input sequences at x_S with N = 5: 34 constraint rows, smallest eigenvalue of H 0.526, costs agreeing to 4.5 \times 10^{-13}, and the constraint test agreeing with the rollout in every case.

  2. B.2, KKT conditions. Write them for the condensed QP and for the problem with the states kept as variables; show that without inequalities the latter reduces to the Riccati recursion, and interpret the multipliers.
    Answer

    (a) U^\star is optimal if and only if there is \mu \ge 0 with HU^\star + f + G^\top\mu = 0, GU^\star \le w and \mu_i(w - GU^\star)_i = 0; with affine constraints these are necessary and sufficient, U^\star is unique because H \succ 0, \mu need not be. (b) With multipliers \lambda_{k+1} for the dynamics and \nu_k, \mu_k, \eta for the inequalities, stationarity reads 2Ru_k + B^\top\lambda_{k+1} + G_u^\top\nu_k = 0, \lambda_k = 2Qx_k + A^\top\lambda_{k+1} + G_x^\top\mu_k and \lambda_N = 2Px_N + G_x^\top\mu_N + H_f^\top\eta: the costates run backwards, as in the discrete-time maximum principle. Without inequalities try \lambda_k = 2P_kx_k: the u_k-condition gives u_k = -(R + B^\top P_{k+1}B)^{-1}B^\top P_{k+1}Ax_k and the x_k-condition the Riccati recursion with P_N = P; with P from the DARE, P_k = P for all k, which is why the MPC equals the LQR inside \mathcal X_f. A multiplier is the price of its constraint: if the active set does not change, \partial J_N^\star / \partial w_i = -\mu_i, so relaxing constraint i by \varepsilon lowers the optimal cost by about \mu_i\varepsilon; C.4 uses this to size slack penalties. The widget below recovers the multipliers at x_S and checks the price.

  1. B.3, recursive feasibility by the shifted sequence. Let x \in \mathcal X_N with optimal plan and predicted states. Show that x^+ = Ax + Bu_0^\star \in \mathcal X_N. Which conditions are used? Is optimality needed?
    Answer

    From x^+ = x_1^\star take the shifted plan (u_1^\star, \ldots, u_{N-1}^\star, -Kx_N^\star). Its states x_2^\star, \ldots, x_N^\star lie in \mathcal X; since x_N^\star \in \mathcal X_f, condition 1 gives -Kx_N^\star \in \mathcal U and condition 2 gives A_Kx_N^\star \in \mathcal X_f \subseteq \mathcal X. So x^+ \in \mathcal X_N. Neither condition 3 nor optimality is used: any feasible plan has a feasible successor, which makes the shifted plan a valid warm start and fallback (C.3, C.6). The argument does need a plant equal to the model (C.1, C.2).

  2. B.4, Lyapunov decrease and the upper bound. Prove J_N^\star(x^+) \le J_N^\star(x) - q(x, u_0^\star), then J_N^\star \le V_f on \mathcal X_f, and say what the bound adds.
    Answer

    The shifted plan costs \tilde J = J_N^\star(x) - q(x, u_0^\star) + [q(x_N^\star, -Kx_N^\star) + V_f(A_Kx_N^\star) - V_f(x_N^\star)], where the bracket is at most zero by condition 3, and J_N^\star(x^+) \le \tilde J by optimality. For x \in \mathcal X_f the plan u_k = -Kx_k is feasible by conditions 1 and 2, and summing condition 3 along it gives \sum_k q(x_k, -Kx_k) + V_f(x_N) \le V_f(x), hence J_N^\star(x) \le V_f(x) \le \lambda_{\max}(P)\|x\|^2. The lower bound J_N^\star \ge \lambda_{\min}(Q)\|x\|^2 and the decrease give \sum_t\|x(t)\|^2 < \infty, hence convergence; only the upper bound makes small initial states stay small, \lambda_{\min}(Q)\|x(t)\|^2 \le J_N^\star(x(t)) \le J_N^\star(x(0)) \le \lambda_{\max}(P)\|x(0)\|^2 for x(0) \in \mathcal X_f. With both bounds quadratic, J_N^\star(x^+) \le (1 - \lambda_{\min}(Q)/c_2)J_N^\star(x) with c_2 = \lambda_{\max}(P) = 1.911 on \mathcal X_f and a larger constant on the bounded \mathcal X_N: exponential stability.

  3. B.5, invariance of the convex safe set. Each stored state s_i has a stored input and successor s_i^+ = As_i + Bu_i, and the target is stored as an equilibrium with u = 0. Show that CS = \operatorname{conv}\{s_i\} is control invariant when \mathcal X and \mathcal U are convex. Which step fails for a nonlinear model, and which for a nonconvex \mathcal X?
    Answer

    Write x = \sum_i\lambda_is_i on the simplex and apply u = \sum_i\lambda_iu_i \in \mathcal U. By linearity Ax + Bu = \sum_i\lambda_is_i^+ \in CS, because every successor is a stored state; and CS \subseteq \mathcal X by convexity. For a nonlinear model the linearity step fails, so only the sampled set stays invariant, which leads to mixed-integer problems or local convexifications (Part 8). For a nonconvex \mathcal X, such as chapter 04's obstacle avoidance, a convex combination of admissible states can be inadmissible.

  4. B.6, the barycentric terminal cost. With V_c(x) = \min\{\mathbf J^\top\lambda : S^\top\lambda = x,\ \mathbf 1^\top\lambda = 1,\ \lambda \ge 0\}, show that (a) V_c is convex on CS with V_c(s_i) \le J_i; (b) with \lambda optimal at x and u = \sum_i\lambda_iu_i, V_c(Ax + Bu) \le V_c(x) - q(x, u); (c) V_c \ge J_\infty^\star on CS.
    Answer

    (a) If \lambda, \lambda' are optimal at x, x', then \theta\lambda + (1 - \theta)\lambda' is feasible at \theta x + (1 - \theta)x' with cost \theta V_c(x) + (1 - \theta)V_c(x'), so V_c is convex, and piecewise affine as the value of an LP with a right-hand side affine in x; choosing \lambda = e_i gives V_c(s_i) \le J_i. Geometrically, the lower convex envelope of the points (s_i, J_i). (b) By linearity Ax + Bu = \sum_i\lambda_is_i^+, so the same weights on the successors are feasible at x^+, and convexity of q gives q(x, u) \le \sum_i\lambda_iq(s_i, u_i); hence V_c(x^+) \le \sum_i\lambda_iJ_i^+ = \sum_i\lambda_iJ_i - \sum_i\lambda_iq(s_i, u_i) \le V_c(x) - q(x, u). With B.5 these are conditions 1 to 3 for \mathcal X_f = CS, V_f = V_c and the local controller \sum_i\lambda_iu_i, so B.3 and B.4 apply to LMPC unchanged. (c) Each J_i is the cost of an admissible trajectory, so J_i \ge J_\infty^\star(s_i), and J_\infty^\star is convex (linear dynamics, convex constraints and cost); for \lambda optimal at x, V_c(x) = \sum_i\lambda_iJ_i \ge \sum_i\lambda_iJ_\infty^\star(s_i) \ge J_\infty^\star(x). The learned terminal cost is pessimistic, which is the mechanism behind the plateau of Part 5.

Part 7

Engineering judgment

Parts 1 to 6 assumed an exact model, an exact solver and a measured state. What if they fail?

C.1. Model mismatch: the plant is (A + \Delta A, B + \Delta B), the MPC uses (A, B). Which guarantees survive?

Strictly, none: every proof used x^+ = x_1^\star. With a continuous value function, linear MPC has some inherent robustness, so for small mismatch the state still reaches a neighbourhood of the origin. Near active constraints, however, a small error can push the state out of \mathcal X_N, into the doomed states of Part 4. Remedies: a better model, constraint margins, offset-free MPC with an integrating disturbance model and an observer, or a robust design (C.2).

C.2. Disturbances: x^+ = Ax + Bu + w with w \in \mathcal W bounded. How can constraint satisfaction and recursive feasibility be guaranteed?

Tube MPC (Mayne, Seron and Raković [8]) plans for the nominal model z^+ = Az + Bv and applies u = v + K(x - z). The error e = x - z obeys e^+ = A_Ke + w and stays in a robust positively invariant set \mathcal E with A_K\mathcal E \oplus \mathcal W \subseteq \mathcal E. Planning with the tightened sets \mathcal X \ominus \mathcal E and \mathcal U \ominus K\mathcal E makes B.3 apply to z, and x \in z \oplus \mathcal E \subseteq \mathcal X for every disturbance sequence. The price is a smaller feasible set and convergence to \mathcal E instead of the origin.

C.3. Real-time solvers: the QP must be solved within one sampling period. What are the options, and what if the solver does not finish?

Small dense QPs suit warm-started active-set solvers (qpOASES); long horizons favour sparse interior-point (HPIPM) or first-order (OSQP) methods; tiny problems can use the explicit piecewise-affine law of B.1. If the solver stops early, the shifted plan of B.3 is feasible, and any feasible plan that costs no more preserves the decrease of B.4: feasibility implies stability (Scokaert, Mayne and Rawlings [7]). As Part 3 showed, a failure flag must be checked, not trusted.

C.4. Soft constraints: how should constraints be softened so that the QP is always feasible, and how large must the penalty be?

Use G_xx_k \le g_x + \varepsilon_k with \varepsilon_k \ge 0 and add \rho\,\mathbf 1^\top\varepsilon + \varepsilon^\top S\varepsilon to the cost, for state constraints only, since input bounds are physical limits. If \rho exceeds the largest multiplier of the hard problem (B.2), the penalty is exact: the soft QP returns the hard solution whenever the hard problem is feasible (Kerrigan and Maciejowski [9]). A purely quadratic penalty is never exact. Softening restores feasibility of the QP, not the guarantees.

C.5. Estimation and delays: only y = Cx + v is measured, and the input acts after d steps. What changes?

An observer, a Kalman filter or moving-horizon estimation which handles constraints, provides \hat x. Using \hat x as if it were x is standard, but the separation principle does not extend to constrained MPC: the estimation error acts as a disturbance, which output-feedback tube MPC covers by tightening the constraints. A known delay is handled by prediction: solve from x(t + d), predicted with the inputs already sent. Computation time is a one-step delay of the same kind.

C.6. Safety fallbacks: what should the controller do when the QP is infeasible or the solver fails?

Use layers: the rest of the previous plan, feasible for N - 1 steps in the nominal case (B.3) and followed by -Kx inside \mathcal X_f; then a softened QP that minimises the violation (C.4); last, a backup controller with its own invariant set, such as maximal braking, certified offline. An independent check like the LP of Part 3 tells "no admissible plan exists" apart from "the solver failed". In LMPC, the stored continuation u = \sum_i\lambda_iu_i of B.5 keeps the state in CS^j.

Part 8

Where to go next

Robust and stochastic MPC. Tube MPC (C.2), constraint tightening and min-max formulations for bounded disturbances; chance constraints and stochastic tubes for random ones. See Rawlings, Mayne and Diehl [2], chapter 3, and Kouvaritakis and Cannon [12].

Nonlinear and economic MPC. For nonlinear models, terminal ingredients come from the linearisation at the equilibrium (quasi-infinite-horizon MPC, Chen and Allgöwer [10]). Without terminal ingredients, stability can be proved for long enough horizons under controllability assumptions (Grüne and Pannek [11]): the route to turning the observations of Part 4 into guarantees. Economic MPC drops positive-definite stage costs and replaces the Lyapunov argument by dissipativity.

Learning MPC beyond linear systems. The convex safe set is not invariant for nonlinear dynamics (B.5). The alternatives are a sampled safe set with a mixed-integer terminal constraint, or local convex safe sets with local models identified from data, as in the racing chapters 06 and 07 (Rosolia and Borrelli [5]).

Data-driven models. Identification with error bounds feeds robust MPC, Gaussian-process models provide uncertainty estimates, and methods based on Willems' fundamental lemma replace the model by a Hankel matrix of measured data (Coulson, Lygeros and Dörfler [14]).

Embedded solvers. OSQP (operator splitting), qpOASES (parametric active set), HPIPM and acados (structure-exploiting interior point and code generation), and explicit MPC by multiparametric programming (Bemporad et al. [13]).

Projects on the course repository. Replace SLSQP in the QP wrapper by an active-set or ADMM solver and rerun the audit of Part 3. Add a disturbance |w_i| \le 0.05, implement tube MPC, and repeat the grid check. Soften the state constraints with an exact penalty (C.4) and test it under model mismatch. Repeat Part 5 from other first trajectories: does the N = 2 plateau move?

Part 9

The course on one page

  1. LQR terminal ingredients: V_f decreases with equality, \mathcal X_f is limited by the input bound, and the feasible sets \mathcal X_N are nested, control invariant and equal to \mathcal C_\infty from N = 5.
  2. Grid certificate: over 17 640 closed-loop QPs, no loss of feasibility, a decrease residual of at most 5.3 \times 10^{-8}, and J_N^\star = V_f on \mathcal X_f. The single SLSQP failure was a degenerate but feasible QP, certified by an LP.
  3. No terminal ingredients: N = 1 lost feasibility from 100 states of \mathcal C_\infty, N = 2 accepted doomed states and cost up to 2.15\, J_\infty^\star. From N = 3 on the grid behaved, but without a certificate.
  4. Learning MPC: from 1.69\, J_\infty^\star the costs never increased. N = 4 reached J_\infty^\star, while N = 2 and N = 3 stalled 0.30 and 0.13 percent above it, because V_c is pessimistic between data.
  5. Derivations: the condensed QP is a multiparametric QP; its KKT system contains the Riccati recursion; the shifted sequence proves feasibility, the terminal decrease proves stability; the convex safe set and the barycentric cost satisfy the same three conditions from data.
  6. Judgment: every proof needs plant equal to model; tubes buy robustness with region; a solver flag is not a certificate; penalties restore feasibility of the QP, not the guarantees; observers add a disturbance; fallbacks are layered.
