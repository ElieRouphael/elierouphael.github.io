Reference tracking and offset-free MPC

Every controller so far drove the cart to the origin. A real controller is given a setpoint, and the setpoint changes. The regulator of Part A handles that with a change of variables, as long as the model is right. When it is not, when the cart sits on a slope the model knows nothing about, the controller settles a fixed distance from where it was told to go, and no amount of tuning moves it. The repair is an observer that estimates the slope from the measured position and a target that accounts for it. Below, both controllers run on the same sloping cart.

Part 1

Where the cart can sit still

A setpoint is a value of the output that the cart must hold. With the position measured, y = Cx, C = (1, 0), holding y = r means finding a steady state, a pair (x_s, u_s) that the model leaves where it is and whose output is r:

\boxed{x_s = Ax_s + Bu_s, \qquad Cx_s = r}, \qquad \text{that is}\qquad \begin{pmatrix} I - A & -B \\ C & 0 \end{pmatrix} \begin{pmatrix} x_s \\ u_s \end{pmatrix} = \begin{pmatrix} 0 \\ r \end{pmatrix}.

Three equations in three unknowns. For the cart the answer is obvious once written: a cart sits still only at zero velocity, and holds zero velocity only with zero input, so x_s = (r, 0) and u_s = 0 for every r. The determinant of the 3 \times 3 system is 1, so the target is unique; for a plant with more inputs than outputs the system is underdetermined and a least-cost target is chosen, for one with fewer, a least-squares one, and both are the target problem of tracking MPC (Rawlings, Mayne and Diehl [1], chapter 1.5). Everything that follows is built on the target: the controller never sees r directly, only (x_s, u_s).

Part 2

The regulator of A11 around a setpoint

Write the state and input as deviations from the target, \delta x = x - x_s and \delta u = u - u_s. Because the target is a steady state of the model, the deviations obey the same dynamics,

\delta x^+ = A\,\delta x + B\,\delta u,

and driving \delta x to zero is exactly chapter A11's regulation problem, with its stage cost q(\delta x, \delta u), its Riccati terminal cost and its LQR gain unchanged. Two things do change.

The constraints move. |p| \le 4 becomes -4 - r \le \delta p \le 4 - r, and |u| \le 1 becomes -1 - u_s \le \delta u \le 1 - u_s: the box is no longer centred on the equilibrium, and the room on the side of the setpoint shrinks as r approaches the wall.

The terminal set must be recomputed. The LQR's invariant set of chapter A10 was built inside the symmetric box; around (r, 0) it has to be built inside the shifted one, where the LQR input stays admissible and the next state stays inside, which the same fixed-point iteration delivers. At r = 0 it is the familiar parallelogram of area 7.31; at r = 2 it loses its right corner and has area 6.83; at r = 3.5 it is squeezed to 4.45 with only half a unit of room on the setpoint's side; at r = 3.8 the iteration returns a five-vertex set of area 3.87. A terminal set that depends on the setpoint is the price of hard constraints near the wall, and the reason tracking MPC with changing references needs either a recomputation at every change or the artificial-setpoint formulation of Limón and colleagues [4], which keeps one invariant set for all targets.

What the regulator theorem gives. With the shifted constraints and terminal set, every statement of chapter A11 holds for \delta x: recursive feasibility, the Lyapunov decrease, exponential convergence to x_s from the feasible region. The model, not the controller, is what will fail next.

Part 3

A slope the model does not know

Put the cart on a slope. Gravity adds a constant acceleration that the motor must fight: the plant is

x^+ = Ax + B(u + d), \qquad d = -0.2,

while the controller's model has no d. Nothing is wrong with the controller: its problem is feasible, its value decreases, its deviation converges. It converges to the wrong place.

Why, in one line. Near the target the controller is the LQR, \delta u = -K\,\delta x, so the deviation obeys \delta x^+ = (A - BK)\,\delta x + Bd, a stable linear system with a constant input, whose fixed point is

\boxed{\delta x_{ss} = (I - A_K)^{-1} B d = (-0.270,\ 0)}.

The cart stops 0.270 short of every setpoint, at zero velocity, with the input -K\,\delta x_{ss} = +0.2: the position error is what supplies the input that cancels the slope. A larger K would shrink the offset, never remove it; an integrator would remove it, and the LQR has none. The numbers script runs plain tracking MPC with r = 2 for thirty steps and then r = -1 for thirty: the position settles at 1.730 and then at -1.270, the same offset both times, with the input at 0.200 at the end. The first setpoint is reached at the input bound, u = 1, then the controller eases off; the offset is already there by step 10 and never changes.

Part 4

An integrating disturbance state and its observer

What is offset-free MPC?

In plain words: give the model a state for what it does not know, a constant disturbance; estimate that state from the measurements with an observer; and aim the controller at the target that the estimated disturbance implies, so that the controller's steady state is the plant's steady state.

More precisely: augment the model with d^+ = d and x^+ = Ax + B(u + d), estimate (\hat x, \hat d) with a Luenberger observer driven by y - C\hat x, solve the target problem with the estimate, x_s = Ax_s + B(u_s + \hat d), Cx_s = r, and apply the deviation controller to \hat x - x_s. If the augmented model is detectable and the closed loop converges, the output converges to r with no offset (Pannocchia and Rawlings [2], Maeder, Borrelli and Morari [3]).

Augmented state
(x, d): the cart's state and the unknown constant, three numbers.
Observer
\hat x_t = \bar x_t + L(y_t - C\bar x_t), then \bar x_{t+1} = A_a \hat x_t + B_a u_t: predict, correct with the measurement.
Detectability
The disturbance must be visible in the output in a way the state cannot imitate; a rank test decides.
Target with \hat d
For the cart, x_s = (r, 0) and u_s = -\hat d: the input the slope requires.

The augmented model. With x_a = (p, v, d),

A_a = \begin{pmatrix} 1 & 1 & 0.5 \\ 0 & 1 & 1 \\ 0 & 0 & 1 \end{pmatrix}, \qquad B_a = \begin{pmatrix} 0.5 \\ 1 \\ 0 \end{pmatrix}, \qquad C_a = (1, 0, 0).

The slope enters the velocity like the input does. Is it observable from the position alone? The observability matrix of (A_a, C_a) has rank 3: the position's first differences give the velocity, its second differences give the acceleration, and the acceleration is u + d with u known. The rank test of Pannocchia and Rawlings, \mathrm{rank} \begin{pmatrix} I - A & -B_d \\ C & C_d \end{pmatrix} = n + n_d with B_d = B, C_d = 0, gives 3 as well.

The observer. A Luenberger observer in current-estimator form corrects the predicted augmented state with the measurement that has just arrived, then predicts the next one:

\hat x_t = \bar x_t + L\,(y_t - C_a \bar x_t), \qquad \bar x_{t+1} = A_a \hat x_t + B_a u_t.

Its estimation error obeys e_{t+1} = A_a (I - LC_a)\, e_t, and L is chosen to place the eigenvalues of that matrix. The numbers script does it by pole placement on the dual pair: for eigenvalues 0.5, 0.55, 0.6 the gain is L = (0.835, 0.470, 0.090); faster, 0.3, 0.35, 0.4, gives (0.958, 0.856, 0.273); slower, 0.8, 0.85, 0.9, gives (0.388, 0.061, 0.003). A larger gain trusts the measurement more and converges faster, and would amplify measurement noise more, which this noiseless chapter does not show.

The target with the estimate. Solving the target equations with \hat d in place of the unknown slope gives x_s = (r, 0) as before and u_s = -\hat d: the controller is told to hold the input that cancels the slope, and regulates the deviation from there. When \hat d converges to d the controller's equilibrium is the plant's.

Part 5

Two setpoints, two controllers, one slope

The offset-free controller starts identically, with the input saturated at 1, because \hat d is still zero; by step 5 the estimate has reached -0.123 and the two inputs part ways. It is within 0.01 of the first setpoint from step 17, and after the change at step 30 it is within 0.01 of -1 from step 36, six steps later: the estimate is already right, so the second step is a pure regulation transient. The plain controller sits at 1.730 and -1.270 for ever. Both end with the same input, u = 0.200, but for different reasons: the plain controller's error produces it, the offset-free controller's target prescribes it.

Observer speed. With the faster observer the estimate is at -0.182 after five steps and the position settles from step 10; with the slower one it is at -0.011 after five steps and -0.044 after ten, and the position is not within 0.01 of the setpoint after thirty steps. The observer's eigenvalues set how long the offset lasts, not whether it goes. Nothing becomes infeasible in any of the three runs; the hero reports when it does, holding the last input, since a bad estimate can place \hat x outside the feasible region.

Part 6

Input against output disturbance, and detectability

The disturbance could have been modelled on the output instead, y = p + d with d^+ = d, the choice many implementations make by default. On the cart it fails, and the failure is instructive.

The rank test. With B_d = 0 and C_d = 1 the matrix \begin{pmatrix} I - A & 0 \\ C & 1 \end{pmatrix} has rank 2, not 3: the augmented pair is not detectable. The reason is physical. The cart is itself an integrator, so a constant position with zero velocity is an equilibrium of the model, and a constant output offset produces the same measurements as that equilibrium shifted: the observer cannot tell the two apart. Pole placement still returns a gain, because the software does not check, and the numbers script runs the loop anyway: the position is at 40 after ten steps and 360 after thirty, the estimate is at 10^{14}, and the tracking problem is infeasible from the first step. For a plant with integrators the disturbance must enter where the integrator does not already explain it, which here means the input. For an asymptotically stable plant either model is detectable, and the choice affects the transient, not the offset; Pannocchia and Rawlings [2] give the general conditions and the number of disturbance states, one per measured output, that offset-free tracking needs.

Part 7

The code behind it

The package's controller already accepts a reference. The relevant lines of its solve are the ones that build the linear term of the QP.

advanced_mpc_lmpc/mpc.py · LinearMPC.solve

    def solve(self, x0, x_ref=None, extra_A_ub=None, extra_b_ub=None, warm=None):
        x0=np.asarray(x0,float).reshape(self.n)
        x_ref=np.zeros(self.n) if x_ref is None else np.asarray(x_ref,float).reshape(self.n)
        Qbar=np.kron(np.eye(self.N),self.Q)
        Qbar[-self.n:,-self.n:]=self.P
        Rbar=np.kron(np.eye(self.N),self.R)
        rstack=np.tile(x_ref,self.N)
        base=self.Sx@x0-rstack
        H=2*(self.Su.T@Qbar@self.Su+Rbar)
        f=2*self.Su.T@Qbar@base
        Aubs=[]; bubs=[]
        if self.x_upper is not None:
            Aubs.append(self.Su); bubs.append(np.tile(self.x_upper,self.N)-self.Sx@x0)
        if self.x_lower is not None:
            Aubs.append(-self.Su); bubs.append(-np.tile(self.x_lower,self.N)+self.Sx@x0)
        if self.terminal_H is not None:
            SuN=self.Su[-self.n:]; SxN=self.Sx[-self.n:]
            Aubs.append(np.asarray(self.terminal_H)@SuN)
            bubs.append(np.asarray(self.terminal_h)-np.asarray(self.terminal_H)@SxN@x0)
        if extra_A_ub is not None:
            Aubs.append(np.asarray(extra_A_ub,float)); bubs.append(np.asarray(extra_b_ub,float))
        Aub=np.vstack(Aubs) if Aubs else None
        bub=np.concatenate(bubs) if bubs else None
        lb=np.tile(self.u_lower,self.N) if self.u_lower is not None else None
        ub=np.tile(self.u_upper,self.N) if self.u_upper is not None else None
        res=solve_qp(H,f,A_ub=Aub,b_ub=bub,lb=lb,ub=ub,x0=warm)
        U=res.x.reshape(self.N,self.m)
        X=(self.Sx@x0+self.Su@res.x).reshape(self.N,self.n)
        return MPCSolution(res.success,U,X,res.objective,res.message)

Read x_ref: it is tiled over the horizon and subtracted from the predicted states inside the cost, base = Sx @ x0 - rstack, so the quadratic penalises x_k - x_{\mathrm{ref}} instead of x_k. That is a tracking cost and nothing more. The constraints are not shifted, the terminal set stays where it was built, and no u_s is subtracted from the input, so the controller is correct only for a reference that is an equilibrium with zero input and lies well inside the terminal set. The numbers script does not use x_ref; it builds the deviation problem explicitly, with the shifted box and the recomputed terminal set, which is the honest version.

The target and the observer are small enough to quote in full from the numbers script:

def target(r, d_hat=0.0):
    """Steady state (x_s, u_s) with C x_s = r for x+ = A x + B (u + d)."""
    M = np.block([[np.eye(2) - A, -B], [C, np.zeros((1, 1))]])
    sol = np.linalg.solve(M, np.r_[B.ravel() * d_hat, r])
    return sol[:2], float(sol[2])

def observer_gain(poles, Am=Aa, Cm=Ca):
    """Current-estimator gain: error dynamics A (I - L C); eig(A (I - L C)) = eig(A - (A L) C)."""
    Lp = place_poles(Am.T, Cm.T, poles).gain_matrix.T      # predictor-form gain, eig(A - Lp C) = poles
    return np.linalg.solve(Am, Lp)                          # L = A^{-1} Lp

# one step of the offset-free loop
y = float((C @ x).item())
xh = pred + L.ravel() * (y - float((Ca @ pred).item()))    # correct the prediction with the measurement
x_s, u_s = target(r, xh[2])                                # the target the estimated slope implies
u = u_s + float(mpc.solve(xh[:2] - x_s).U[0].item())       # the deviation controller on the estimate
x = A @ x + B.ravel() * (u + d)                            # the plant, on its slope
pred = Aa @ xh + Ba.ravel() * u                            # predict the next estimate

One detail that cost an afternoon: the pole-placement routine returns the gain of the predictor form, \bar x_{t+1} = A_a \bar x_t + B_a u_t + L_p (y_t - C_a \bar x_t), whose error matrix is A_a - L_p C_a. The current-estimator form used here has error matrix A_a (I - LC_a), and using L_p in it places the eigenvalues somewhere else, unstable for the fast design. The conversion L = A_a^{-1} L_p makes the two forms agree.

Part 8

Common pitfalls

  1. "A reference is a state the cost penalises." A reference is a steady state of the model, (x_s, u_s), and the constraints and the terminal set move with it. A cost term alone, as x_ref provides, is right only for an equilibrium at zero input far from the walls.
  2. "A bigger gain removes the offset." It shrinks (I - A_K)^{-1} B d and never zeroes it. Removing an offset needs an integrator somewhere: here, the disturbance state.
  3. "Any disturbance model will do." The output-disturbance model is not detectable on the cart and the loop diverges. The rank test is the check.
  4. "The observer can be as fast as we like." In this noiseless chapter, yes; with measurement noise a large L passes the noise into the estimate, the target and the input.
  5. "Offset-free means the estimate equals the true disturbance." Only when the disturbance model matches the plant's. In general the estimate is whatever constant makes the model's steady state agree with the measurements, which is enough for the output to reach the setpoint.
Part 9

Check your understanding

Try to answer each question before opening it.

1. What is a steady-state target, and why does the cart's not depend on r except through the position?

A pair (x_s, u_s) with x_s = Ax_s + Bu_s and Cx_s = r. The cart sits still only at zero velocity with zero input, so x_s = (r, 0) and u_s = 0 for every r.

2. Why does chapter A11's regulator apply to tracking unchanged?

Deviations from a steady state obey the same linear dynamics, so regulating \delta x to zero is the same problem with the same cost and gain. Only the constraints and the terminal set move.

3. Why does the terminal set shrink near the wall?

It is the LQR's invariant set inside the shifted box; as the setpoint approaches a bound, the room on that side disappears and states that would step over it are excluded. At r = 3.5 its area is 4.45 against 7.31 at the origin.

4. Where does the offset (I - A_K)^{-1} B d come from?

Near the target the loop is \delta x^+ = A_K\,\delta x + Bd; its fixed point is the offset. The position error produces the input +0.2 that holds the cart against the slope.

5. What does the observer estimate, and from what?

The cart's state and the constant slope, from the measured position alone, which is possible because the slope shows up in the position's second differences once the input is known.

6. How does the estimate remove the offset?

Through the target: u_s = -\hat d prescribes the input the slope requires, so the controller's equilibrium coincides with the plant's once \hat d = d.

7. Why does the output-disturbance model fail on the cart?

The cart integrates, so a constant output offset and a shifted equilibrium of the model give the same measurements; the augmented pair is not detectable and the rank test returns 2 of 3.

8. Why must the pole-placement gain be converted for the current estimator?

Pole placement gives L_p with \mathrm{eig}(A_a - L_p C_a) at the chosen values; the current estimator's error matrix is A_a(I - LC_a), whose eigenvalues match those of A_a - (A_a L)C_a, so L = A_a^{-1} L_p.

Part 10

Exercises

Each exercise has a hint and a solution; the code runs with the course package installed. Try first, then peek.

  1. The target equations by hand. Solve x_s = Ax_s + Bu_s, Cx_s = r for the cart, then with the slope: x_s = Ax_s + B(u_s + d).

    Hint

    Write the two state equations out; the velocity equation forces the input.

    Solution

    p_s = p_s + v_s + u_s / 2 and v_s = v_s + u_s give u_s = 0 then v_s = 0, and Cx_s = r gives p_s = r. With the slope, v_s = v_s + u_s + d gives u_s = -d: the target input cancels the slope, and the position equation is then satisfied with v_s = 0. That is why offset-free tracking on the cart changes u_s and nothing else.

  2. The offset. Derive \delta x_{ss} = (I - A_K)^{-1} B d and compute it for d = -0.2 and d = 0.3; check both against the plain controller's steady state.

    Hint

    Set \delta x^+ = \delta x in the closed loop \delta x^+ = A_K \delta x + Bd.

    Solution

    (I - A_K)\,\delta x_{ss} = Bd. With the canonical gain, \delta x_{ss} = (-0.2704, 0) for d = -0.2 and (0.4056, 0) for d = 0.3; the numbers script's plain controller settles at 2 - 0.2704 = 1.7296 and at 2.4056. The offset is linear in d and independent of the setpoint.

  3. Build it: the observer. Implement the current-estimator observer yourself with the gain L = (0.835, 0.470, 0.090), run it on the sloping cart under the plain controller's inputs, and check that \hat d converges to -0.2 and \hat x to x.

    Hint

    Two lines per step: correct with y_t, predict with u_t. Start from \bar x_0 = 0.

    Solution

    The estimation error obeys e_{t+1} = A_a(I - LC_a)\,e_t whatever the inputs, so the observer converges under any controller; with eigenvalues 0.5 to 0.6 the error shrinks by about half per step and \hat d is within 0.01 of -0.2 in about ten steps. Feeding the estimate to the plain controller changes nothing, since that controller ignores \hat d; feeding it through the target is what removes the offset.

  4. The detectability test. Compute the rank of \begin{pmatrix} I - A & -B_d \\ C & C_d \end{pmatrix} for the input-disturbance model (B_d = B, C_d = 0) and the output-disturbance model (B_d = 0, C_d = 1). Then replace the cart by the stable scalar plant x^+ = 0.5x + u, y = x, and repeat.

    Hint

    For the cart I - A has rank 1.

    Solution

    Cart: input model rank 3, output model rank 2, so only the input model is detectable, as Part 6 says. Scalar stable plant: I - A = 0.5 \ne 0, and both models give rank 2 of 2, so either removes the offset; they differ in the transient. The integrator is what breaks the output model, because a constant output offset is then indistinguishable from a shifted equilibrium.

  5. No slope. Run both controllers with d = 0. Do they differ?

    Hint

    What is \hat d when the model is right?

    Solution

    The estimate stays at zero, the target is (r, 0) with u_s = 0 for both, and the two controllers are the same controller: both reach 2.000. Offset-free MPC costs nothing when the model is right; it is insurance for when it is not.

  6. A setpoint at the wall. Set r = 3.8 with the slope. What happens to the terminal set and to the deviation problem's feasibility from rest, and what does the hero do when the problem is infeasible?

    Hint

    Part 2's widget at r = 3.8; the deviation box leaves 0.2 on the right.

    Solution

    The terminal set is a five-vertex sliver of area 3.87 and the deviation box has only 0.2 of room on the setpoint's side. From rest the problem is still feasible, since the controller can approach slowly, but an overshooting estimate can push \hat x - x_s outside the feasible region; the hero then holds the last input and reports the step. A controller near a wall needs either a margin on the setpoint or the artificial-setpoint formulation that keeps the problem feasible for every reachable target.

Part 11

The chapter on one page

  1. The target (x_s, u_s) solves x_s = Ax_s + Bu_s, Cx_s = r: for the cart (r, 0) and u_s = 0, unique.
  2. Deviation variables turn tracking into chapter A11's regulation; the box and the terminal set move with the setpoint (area 7.31 at the origin, 4.45 at r = 3.5).
  3. A slope d = -0.2 the model ignores leaves the offset (I - A_K)^{-1} B d = -0.270 at every setpoint; the error supplies the input 0.2.
  4. Augment with d^+ = d; observable from the position; observer \hat x = \bar x + L(y - C_a\bar x) with L = (0.835, 0.470, 0.090) for eigenvalues 0.5 to 0.6.
  5. Aim at the estimated target, u_s = -\hat d: the offset vanishes, within 0.01 in 17 steps from rest and 6 after a setpoint change.
  6. Detectability decides the disturbance model: the output model fails its rank test on the cart and the loop diverges.

The vocabulary, in one table

Word Meaning
Setpoint r, target (x_s, u_s) The output to hold; the steady state of the model that holds it.
Deviation variables \delta x = x - x_s, \delta u = u - u_s: regulation to zero in disguise.
Offset The steady-state error (I - A_K)^{-1} B d a constant disturbance leaves.
Augmented model (x, d) with d^+ = d: the model plus a state for what it does not know.
Observer, gain L Predict and correct; L places the error eigenvalues.
Current estimator Corrects with the measurement that has just arrived; gain A_a^{-1} times the predictor's.
Detectability The disturbance is visible in the output in a way the state cannot imitate; a rank test.
Offset-free MPC Observer plus target with \hat d plus the deviation controller.

Scope. Constant disturbances on a linear plant with a measured output and no noise; one disturbance state for one output. Noisy measurements, drifting disturbances, references that change every step, and the artificial-setpoint formulation that keeps one terminal set for every target are outside the chapter; Part 2 and the references say where to find them.
