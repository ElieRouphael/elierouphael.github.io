Part 1

The idea: Newton's method on the KKT system, from inside

Chapter A3 ended with four conditions that the solution of

\min_z\ \tfrac12 z^\top H z + f^\top z \quad \text{s.t.}\quad G z \le g, \quad E z = e

must satisfy. Write the inequality with a slack s \ge 0, Gz + s = g, and the KKT system reads

H z + f + G^\top \lambda + E^\top \nu = 0, \qquad G z + s = g, \qquad E z = e, \qquad s \ge 0,\ \lambda \ge 0, \qquad s_i \lambda_i = 0 .

Three of these are linear in the unknowns (z, s, \lambda, \nu). Only the last, complementary slackness, is not, and it is also the one that makes the problem combinatorial: which s_i are zero (active rows) and which \lambda_i are zero (inactive rows) is not known in advance.

What is a primal-dual interior-point method?

In plain words: instead of guessing the active set, replace "s_i \lambda_i = 0" by "s_i \lambda_i = a small positive number", solve the now smooth system by Newton's method while keeping s and \lambda strictly positive, and shrink the small number towards zero. The iterates approach the solution from inside the feasible region and settle on the active constraints only at the end.

More precisely: for a centring parameter \sigma \in (0, 1) and the average complementarity \mu = s^\top \lambda / m, each iteration takes one Newton step on the perturbed system with s_i \lambda_i = \sigma \mu, shortens the step so that s > 0 and \lambda > 0 remain, and repeats until every residual is below a tolerance. The path \{(z, s, \lambda) : s_i \lambda_i = \mu\} traced as \mu \to 0 is the central path.

Primal-dual
z and the multipliers are updated together; the multipliers are part of the answer, not recovered afterwards.
Interior
s > 0 and \lambda > 0 at every iterate; no constraint is touched before convergence.
Fraction to the boundary
The step is cut to at most 99% of the distance to the first s_i or \lambda_i that would reach zero.

The hero shows it: from z^0 = 0 the iterates move towards c, bend as the constraint comes into play, and converge to (0.7, 0.3) along the inside of the half-plane. One Newton step puts the linear residuals at round-off; what the remaining steps do is shrink s \lambda by a factor of about \sigma each.

Part 2

Stacking the rows, and a starting point

The package's solve_qp accepts rows A_ub z <= b_ub, equalities A_eq z = b_eq and bounds lb <= z <= ub, the same signature as the SLSQP wrapper it replaced. Its first job is to turn all inequalities into one matrix.

advanced_mpc_lmpc/qp.py · stack_inequalities

def stack_inequalities(n, A_ub=None, b_ub=None, lb=None, ub=None):
    """Return G, g with G z <= g: the user's rows, then the finite upper bounds, then the finite lower bounds."""
    rows, rhs = [], []
    if A_ub is not None:
        rows.append(np.asarray(A_ub, float).reshape(-1, n)); rhs.append(np.asarray(b_ub, float).reshape(-1))
    if ub is not None:
        ub = np.asarray(ub, float).reshape(-1)
        idx = np.where(np.isfinite(ub))[0]
        if idx.size:
            E = np.zeros((idx.size, n)); E[np.arange(idx.size), idx] = 1.0
            rows.append(E); rhs.append(ub[idx])
    if lb is not None:
        lb = np.asarray(lb, float).reshape(-1)
        idx = np.where(np.isfinite(lb))[0]
        if idx.size:
            E = np.zeros((idx.size, n)); E[np.arange(idx.size), idx] = -1.0
            rows.append(E); rhs.append(-lb[idx])
    if not rows:
        return np.zeros((0, n)), np.zeros(0)
    return np.vstack(rows), np.concatenate(rhs)

The user's rows come first, then one row e_i^\top z \le u_i for every finite upper bound and one row -e_i^\top z \le -l_i for every finite lower bound; infinite bounds are skipped. Treating bounds as ordinary rows costs a little efficiency and buys simplicity: there is one kind of inequality in the rest of the solver, and the multipliers come back in the same order, which is how chapter A5 names the active bound of each input. For the hand QP with z \ge 0 and z_1 \le 2 the stacked system is four rows: (1, 1) \le 1, (1, 0) \le 2, (-1, 0) \le 0, (0, -1) \le 0.

Then the starting point, lines z = ... to nu = np.zeros(p) of solve_qp: z is zero, or the caller's x0, projected into the bounds; the slack is s = \max(g - Gz, 1), which is positive whatever z is, so the start need not be feasible; \lambda = 1 and \nu = 0. An interior-point method does not need a good start, and the solver ignores a warm start's quality beyond this projection. For the hand QP: z^0 = 0, s^0 = 1, \lambda^0 = 1, as the hero's first row shows.

Part 3

The residuals are the KKT conditions

advanced_mpc_lmpc/qp.py · solve_qp

def solve_qp(H, f=None, A_ub=None, b_ub=None, A_eq=None, b_eq=None,
             lb=None, ub=None, x0=None, tol=1e-9, maxiter=100, sigma=0.1, trace=None):
    """Solve the convex QP by a primal-dual interior-point method.

    H must be positive semidefinite (it is symmetrised).  `x0` is accepted for
    API compatibility and used as the starting primal point after projection
    into the bounds; an interior-point method does not need a warm start.

    The iteration solves the perturbed KKT system
        H z + f + G' lam + E' nu = 0,      G z + s = g,   s > 0,  lam > 0,
        E z = e,                           s_i lam_i = sigma * mu,
    by Newton's method, with the step shortened so that s and lam stay
    positive, and sigma = 0.1 pulling the complementarity products towards
    zero.  It stops when every residual is below `tol`, then polishes the
    answer: the constraints the iterate presses against (lam_i > s_i) are
    taken as the active set and the equality-constrained QP on that set is
    solved exactly; the polished point is kept if it is feasible and its
    multipliers are non-negative, which brings the solution to round-off.
    If `trace` is a list, every iterate (z, s, lam, residual, mu) is appended to it.
    """
    H = np.asarray(H, float)
    H = 0.5 * (H + H.T)
    n = H.shape[0]
    f = np.zeros(n) if f is None else np.asarray(f, float).reshape(n)
    G, g = stack_inequalities(n, A_ub, b_ub, lb, ub)
    if A_eq is not None:
        E = np.asarray(A_eq, float).reshape(-1, n); e = np.asarray(b_eq, float).reshape(-1)
    else:
        E = np.zeros((0, n)); e = np.zeros(0)
    m, p = len(g), len(e)

    # starting point: z inside the bounds, slacks and multipliers strictly positive
    z = np.zeros(n) if x0 is None else np.asarray(x0, float).reshape(n).copy()
    if lb is not None:
        lo = np.asarray(lb, float).reshape(-1); z = np.where(np.isfinite(lo), np.maximum(z, lo), z)
    if ub is not None:
        hi = np.asarray(ub, float).reshape(-1); z = np.where(np.isfinite(hi), np.minimum(z, hi), z)
    lam = np.ones(m)
    s = np.maximum(g - G @ z, 1.0)
    nu = np.zeros(p)

    nit, resid, mu = 0, np.inf, 0.0
    for nit in range(1, maxiter + 1):
        rd = H @ z + f + G.T @ lam + E.T @ nu          # dual residual: stationarity of the Lagrangian
        rp = G @ z + s - g                             # primal residual of the inequalities
        re = E @ z - e                                 # primal residual of the equalities
        mu = (s @ lam) / m if m else 0.0               # average complementarity s_i * lam_i
        rc = sigma * mu - s * lam                      # centred complementarity residual
        resid = max(np.abs(rd).max(initial=0.0), np.abs(rp).max(initial=0.0), np.abs(re).max(initial=0.0))
        if trace is not None:
            trace.append((z.copy(), s.copy(), lam.copy(), resid, mu))
        if resid < tol and mu < tol:
            break
        # Newton step on the reduced system: s and lam are eliminated, leaving (dz, dnu)
        D = lam / s
        M = np.zeros((n + p, n + p))
        M[:n, :n] = H + G.T @ (D[:, None] * G)
        M[:n, n:] = E.T
        M[n:, :n] = E
        t = (rc + lam * rp) / s
        rhs = np.r_[-rd - G.T @ t, -re]
        try:
            sol = np.linalg.solve(M, rhs)
        except np.linalg.LinAlgError:
            sol = np.linalg.lstsq(M + 1e-12 * np.eye(n + p), rhs, rcond=None)[0]
        dz, dnu = sol[:n], sol[n:]
        ds = -rp - G @ dz
        dl = (rc - lam * ds) / s
        # fraction-to-the-boundary rule: keep s and lam strictly positive
        a = 1.0
        if m:
            neg_s, neg_l = ds < 0, dl < 0
            if neg_s.any(): a = min(a, float(np.min(-0.99 * s[neg_s] / ds[neg_s])))
            if neg_l.any(): a = min(a, float(np.min(-0.99 * lam[neg_l] / dl[neg_l])))
        zn, sn, ln, nn = z + a * dz, s + a * ds, lam + a * dl, nu + a * dnu
        if not (np.all(np.isfinite(zn)) and np.all(np.isfinite(sn)) and np.all(np.isfinite(ln)) and np.all(np.isfinite(nn))):
            break                                      # keep the last finite iterate for the polish
        z, s, lam, nu = zn, sn, ln, nn
        if a < 1e-12:
            break                                      # stalled at the boundary (a degenerate optimum): polish

    # polish: solve the equality-constrained QP on the active set, accept it if it is feasible and dual feasible.
    # It runs whenever the primal residuals are small, even if the dual ones are not: when more constraints are
    # active than there are variables (a degenerate optimum) the multipliers are not unique and the interior
    # point drifts among them, so the polish recovers one set by least squares, then non-negative least squares.
    prim = max((np.abs(G @ z + s - g).max() if m else 0.0), (np.abs(E @ z - e).max() if p else 0.0))
    if np.all(np.isfinite(z)) and prim < 1e-6:
        act = np.where((lam > s) | (s <= 1e-7 * (1.0 + np.abs(g))))[0] if m else np.zeros(0, int)   # pressed against, or touched
        Ga = G[act]
        k = len(act)
        Mp = np.zeros((n + k + p, n + k + p))
        Mp[:n, :n] = H; Mp[:n, n:n + k] = Ga.T; Mp[n:n + k, :n] = Ga
        Mp[:n, n + k:] = E.T; Mp[n + k:, :n] = E
        sol = np.linalg.lstsq(Mp, np.r_[-f, g[act], e], rcond=None)[0]
        zp, lp, nup = sol[:n], sol[n:n + k], sol[n + k:]
        if np.all(np.isfinite(zp)) and (not m or np.max(G @ zp - g) <= 1e-9) and (not p or np.max(np.abs(E @ zp - e)) <= 1e-9):
            grad = H @ zp + f
            if np.any(lp < -1e-9) or np.abs(grad + Ga.T @ lp + E.T @ nup).max(initial=0.0) > 1e-8:
                from scipy.optimize import nnls
                C = np.hstack([Ga.T, E.T, -E.T]) if (k or p) else np.zeros((n, 0))
                coef = nnls(C, -grad)[0] if C.shape[1] else np.zeros(0)
                lp, nup = coef[:k], coef[k:k + p] - coef[k + p:]
            rd = grad + Ga.T @ lp + E.T @ nup
            if np.all(lp >= -1e-9) and np.abs(rd).max(initial=0.0) <= 1e-7:
                z, nu = zp, nup
                lam = np.zeros(m); lam[act] = np.maximum(lp, 0.0)
                s = g - G @ z
                resid = max(np.abs(rd).max(initial=0.0), (np.abs(E @ z - e).max() if p else 0.0))
                mu = 0.0

    viol = [0.0]
    if m: viol.append(float(np.max(G @ z - g)))
    if p: viol.append(float(np.max(np.abs(E @ z - e))))
    max_v = max(viol)
    converged = bool(resid < 10 * tol and mu < 10 * tol and max_v <= 1e-7)
    message = "KKT conditions satisfied" if converged else f"not converged: residual {resid:.1e}, violation {max_v:.1e}"
    return QPResult(z, converged, float(0.5 * z @ H @ z + f @ z), message, max_v, nit, lam, nu, float(resid))

Read the loop body in order. The first three lines are the linear KKT conditions as residual vectors: rd is stationarity, Hz + f + G^\top \lambda + E^\top \nu; rp is primal feasibility of the inequalities with their slacks, Gz + s - g; re is the equalities, Ez - e. Then mu, the average complementarity s^\top \lambda / m, and rc, the residual of the perturbed complementarity s_i \lambda_i = \sigma \mu, written as \sigma \mu - s_i \lambda_i. The scalar resid is the largest entry of the three linear residuals and, with mu, decides the stopping test. If the caller passed a list as trace, the iterate is recorded here, which is how the hero's table and the numbers script see inside the loop.

The Newton system comes next. With D = \lambda / s (elementwise) the full system in (\Delta z, \Delta s, \Delta \lambda, \Delta \nu) is reduced by eliminating \Delta s and \Delta \lambda: the matrix M is \begin{pmatrix} H + G^\top D G & E^\top \\ E & 0 \end{pmatrix} and the right-hand side carries the residuals, with the vector t collecting the complementarity and primal residuals divided by s. Part 4 derives it. np.linalg.solve does the work; if M is singular, which happens only for redundant equalities, a least-squares solve with a tiny regularisation stands in. The recovered ds and dl follow from the two eliminated equations.

The step is then shortened by the fraction-to-the-boundary rule, Part 5, and all four unknowns move together by the same a. A non-finite iterate, which an infeasible problem can produce, ends the loop early. After the loop comes the polish of Part 6, then the result: the solution, the multipliers split back into lam and nu, the largest constraint violation, the number of iterations, a success flag that means "the KKT residuals are below the tolerance and the point is feasible", and the final kkt_residual for the caller to inspect.

Part 4

The Newton system, with s and \lambda eliminated

Linearising the perturbed KKT system at the current iterate gives, for the step (\Delta z, \Delta s, \Delta \lambda, \Delta \nu),

\begin{aligned} H \Delta z + G^\top \Delta \lambda + E^\top \Delta \nu &= -r_d, \\ G \Delta z + \Delta s &= -r_p, \\ E \Delta z &= -r_e, \\ \Lambda \Delta s + S \Delta \lambda &= r_c, \end{aligned}

with S = \mathrm{diag}(s), \Lambda = \mathrm{diag}(\lambda) and r_c = \sigma \mu \mathbf 1 - S \Lambda \mathbf 1. The last two equations are cheap to solve for the eliminated variables: \Delta s = -r_p - G \Delta z and \Delta \lambda = S^{-1}(r_c - \Lambda \Delta s). Substituting both into the first,

\boxed{\begin{pmatrix} H + G^\top D G & E^\top \\ E & 0 \end{pmatrix} \begin{pmatrix} \Delta z \\ \Delta \nu \end{pmatrix} = \begin{pmatrix} -r_d - G^\top t \\ -r_e \end{pmatrix}}, \qquad D = S^{-1} \Lambda, \quad t = S^{-1}(r_c + \Lambda r_p) .

The reduced matrix has the size of z plus the equalities, n + p, whatever the number of inequalities, and its top-left block is the Hessian plus a weighted Gram matrix of the inequality rows. The weights D_i = \lambda_i / s_i are the whole story of an interior-point method: a row that is far from active has a large slack and a tiny multiplier, so its weight vanishes and the row is ignored; a row that is becoming active has s_i \to 0, its weight grows without bound, and the row is enforced ever more rigidly. The active set is never chosen; it emerges from the weights.

Why the linear residuals vanish after one step. For a QP the first three KKT equations are linear, so a full Newton step (a = 1) solves them exactly. The hero's table shows resid at 10^{-16} from iteration 1 on; the remaining iterations only reduce \mu. Whenever the step is cut short by the boundary rule, the linear residuals shrink by the factor 1 - a instead, and recover on the next full step.

Part 5

The step, and when to stop

Fraction to the boundary. The Newton direction may try to make some s_i or \lambda_i negative. The step length is

a = \min\Big(1,\ \min_{\Delta s_i < 0} \frac{-0.99\, s_i}{\Delta s_i},\ \min_{\Delta \lambda_i < 0} \frac{-0.99\, \lambda_i}{\Delta \lambda_i}\Big),

the largest step that keeps every slack and multiplier at least 1% of its current value. On the hand QP the first step is cut to a = 0.95: the full step would have put s at zero, on the constraint, from where the next weight D would be infinite. Staying strictly inside is what keeps the reduced system solvable.

Centring. With \sigma = 0.1 the complementarity target is a tenth of the current average, and the table shows \mu falling by almost exactly that factor at each step: 5 \times 10^{-2}, 7 \times 10^{-3}, 7 \times 10^{-4}, and so on. The numbers script runs the N = 8 MPC QP with \sigma = 0.01, 0.1, 0.5 and needs 12, 13 and 34 iterations: a small \sigma aims at the solution, a large one at the central path. Production solvers choose \sigma adaptively (Mehrotra's predictor-corrector, [1]); the course keeps a constant because every problem here converges in about a dozen steps anyway.

Stopping. The loop ends when resid < tol and mu < tol, with tol = 10^{-9} by default. Tightening it to 10^{-12} costs three more iterations on the MPC QP, loosening it to 10^{-6} saves three: each decade of accuracy is one Newton step, because \mu falls geometrically. The iteration cap, 100, is reached only by problems that have no solution, Part 8.

Part 6

The polish: from 10^{-10} to round-off

An interior-point iterate is never exactly on a constraint: at the end of the hand QP the slack is 10^{-10}, not zero, and \lambda = 1 + 10^{-10}. For a course that quotes residuals to machine precision that is not good enough, and at a degenerate optimum, where more constraints are active than there are variables, the multipliers are not unique and the interior point drifts among them. The last block of solve_qp fixes both.

Once the primal residuals are small, the rows pressed against or touched, \{i : \lambda_i > s_i \text{ or } s_i \approx 0\}, are taken as the active set \mathcal A, and the equality-constrained QP on it is solved as one linear system,

\begin{pmatrix} H & G_{\mathcal A}^\top & E^\top \\ G_{\mathcal A} & 0 & 0 \\ E & 0 & 0 \end{pmatrix} \begin{pmatrix} z \\ \lambda_{\mathcal A} \\ \nu \end{pmatrix} = \begin{pmatrix} -f \\ g_{\mathcal A} \\ e \end{pmatrix},

by least squares, so that a redundant active set does no harm. The polished point is accepted only if it passes the KKT test exactly: every inequality satisfied, the multipliers nonnegative and stationarity at round-off; when the least-squares multipliers come out with a wrong sign, a non-negative least-squares fit of the gradient onto the active normals recovers a valid set. If anything fails, the interior iterate is kept. On the hand QP the active set is \{1\} and the polished system returns (0.7, 0.3) and \lambda = 1 exactly, which is why chapter A3's residuals are 0 and not 10^{-10}.

A degenerate example. Minimise \tfrac12 \lVert z \rVert^2 + (1, 2, 3)^\top z on the simplex z \ge 0, z_1 + z_2 + z_3 = 1, z \le 1. The answer is (1, 0, 0) with the bound z_2 \ge 0 weakly active: its multiplier is exactly zero, so the interior point approaches it slowly, with z_2 \approx 3 \times 10^{-5} at the tolerance. The polish returns z = (1, 0, 0), \nu = -2 and the single nonzero multiplier \lambda = 1 on z_3 \ge 0, in 17 iterations.

Part 7

Against SLSQP, and timings

The package used SciPy's SLSQP before, a sequential quadratic programming method for general nonlinear problems. The numbers script runs both on four problems.

Problem Interior point SLSQP Agreement
The hand QP, 2 variables, 1 row 10 iterations, 0.5 ms, residual 10^{-15} 4 iterations, 0.4 ms 10^{-15}
MPC QP, N = 8, 8 variables, 48 rows + 16 bounds 13 iterations, 0.8 ms, residual 2 \times 10^{-13} 12 iterations, 0.8 ms 4 \times 10^{-5}
MPC QP, N = 20, 20 variables, 120 rows + 40 bounds 13 iterations, 0.9 ms, residual 3 \times 10^{-12} 16 iterations, 4 ms 7 \times 10^{-5}

Three things to read. The interior-point iteration count does not grow with the problem: 13 steps at N = 8 and at N = 20, each step one linear solve, which is the known behaviour of the method. SLSQP's accuracy is its tolerance of 10^{-8} on the objective, so its inputs differ from the exact ones in the fifth decimal, and the old course pages spent paragraphs explaining residuals of that size away; the new solver returns KKT residuals of 10^{-12} and the paragraphs are gone. And both fail on an infeasible problem, with the interior point giving up after seven steps when its iterate becomes non-finite; neither failure is a proof. Timings are for one laptop and vary; the shape of the comparison does not.

Scaling. The reduced system is dense and n + p square, so a solve costs \mathcal O((n + p)^3): fine for the course's few dozen variables, hopeless for the thousands of a sparse long-horizon problem. That is the moment for a structure-exploiting solver (HPIPM, acados), a first-order method (OSQP) or an active-set method with warm starts (qpOASES), all referenced in chapter B6. The algorithm is the same; the linear algebra is not.

Part 8

Infeasibility, certified by an LP

A solver that fails has not proved that no solution exists; it may have stalled, or hit its cap. The course makes the distinction with an independent calculation.

advanced_mpc_lmpc/qp.py · feasibility_margin

def feasibility_margin(n, A_ub=None, b_ub=None, A_eq=None, b_eq=None, lb=None, ub=None):
    """Certify feasibility of a constraint set with an independent linear program.

    Returns the smallest s >= 0 such that some z satisfies A_ub z <= b_ub + s,
    |A_eq z - b_eq| <= s and lb - s <= z <= ub + s.  Zero (to tolerance)
    certifies that the constraints are feasible; a positive value certifies
    that they are not.  Uses SciPy's HiGHS, a solver that shares no code with
    `solve_qp`, so a QP failure can be told apart from an infeasible problem.
    """
    from scipy.optimize import linprog

    G, g = stack_inequalities(n, A_ub, b_ub, lb, ub)
    rows, rhs = [], []
    if len(g):
        rows.append(np.c_[G, -np.ones(len(g))]); rhs.append(g)
    if A_eq is not None:
        E = np.asarray(A_eq, float).reshape(-1, n); e = np.asarray(b_eq, float).reshape(-1)
        rows += [np.c_[E, -np.ones(len(e))], np.c_[-E, -np.ones(len(e))]]
        rhs += [e, -e]
    c = np.r_[np.zeros(n), 1.0]
    res = linprog(c, A_ub=np.vstack(rows), b_ub=np.concatenate(rhs),
                  bounds=[(None, None)] * n + [(0, None)], method="highs")
    return float(res.x[-1]) if res.success else np.inf

Add one variable t \ge 0 and relax every row by it: Gz \le g + t\mathbf 1 and |Ez - e| \le t \mathbf 1. Minimising t is a linear program, solved here by SciPy's HiGHS, which shares no code with solve_qp. Its optimum is zero exactly when the original constraints can all be met, and a positive value is the smallest uniform relaxation that makes them compatible, a certificate that no z satisfies them as they stand. The infeasible pair above has margin 1; the N = 8 MPC QP has margin 0; and the cart at (3, 2) with a three-step horizon has margin 0.333, because its next position 3 + 2 + u/2 \ge 4.5 leaves the box whatever the input, a doomed state in the vocabulary of chapter A10.

Chapter B6 uses this margin as the arbiter whenever a solver reports failure at a corner of the feasible set: a failure with margin zero is a solver artefact, a failure with a positive margin is infeasibility.

Part 9

Common pitfalls

  1. "The solver picks the active constraints." It does not; the weights \lambda_i / s_i do. The active set is read off at the end, for the polish and for the multipliers.
  2. "A warm start speeds up an interior-point method." Barely: the start must be pushed back inside, and the iteration count is set by the decades of \mu to be removed. Active-set methods are the ones that profit from warm starts, which is why they are preferred for MPC at high rates.
  3. "Success means optimal." success means the KKT residuals are below the tolerance and the point is feasible, which for a convex QP is optimality. For a nonconvex problem, chapter A5, the same flag means a local optimum at best.
  4. "Failure means infeasible." Failure means the method did not converge. The feasibility LP decides; chapter B6 shows a solver failing on a feasible, degenerate problem.
  5. "\sigma is a tolerance." It is the fraction of the current complementarity aimed at in the next step: a convergence-rate knob, not an accuracy knob.
Part 10

Check your understanding

Try to answer each question before opening it.

1. Which KKT condition is nonlinear, and how does the method handle it?

Complementary slackness, s_i \lambda_i = 0. The method replaces the zero by \sigma \mu, a positive target that shrinks every iteration, and takes Newton steps on the resulting smooth system.

2. Why are s and \lambda eliminated from the Newton system?

Because their equations are diagonal: \Delta s and \Delta \lambda follow from \Delta z by elementwise formulas, so the system to factorise has only n + p unknowns however many inequalities there are.

3. What do the weights D_i = \lambda_i / s_i do?

They turn constraints on or off continuously: a slack row has a vanishing weight and is ignored, an active row has a huge weight and is enforced. The active set emerges from them.

4. Why must the iterates stay strictly inside?

Because the weights \lambda_i / s_i and the eliminated step \Delta \lambda = S^{-1}(\dots) divide by s. A zero slack breaks the reduced system; the 99% rule prevents it.

5. Why do the linear residuals vanish after one full step on a QP?

Stationarity and feasibility are linear in the unknowns, so one Newton step solves them exactly. Only the complementarity residual needs more steps.

6. What does the polish add?

An exact solve on the detected active set: the solution and multipliers to round-off instead of to the tolerance, and a unique multiplier set at degenerate optima.

7. Why does the course keep a separate feasibility LP?

Because a solver's failure is not a proof. The LP, from a different code base, returns zero for a feasible constraint set and a positive margin otherwise.

8. When is this solver the wrong tool?

For large or sparse problems: its linear algebra is dense and cubic in the number of variables. Structure-exploiting and first-order solvers scale; the algorithm's idea is the same.

  2. A degenerate optimum. Solve \min \tfrac12 \lVert z \rVert^2 + (1, 2, 3)^\top z subject to z_1 + z_2 + z_3 = 1, 0 \le z \le 1. Which bounds are active, which multipliers are zero, and why is the polish needed?

    Hint

    The answer is a vertex of the simplex; count the active constraints against the number of variables.

    Solution

    z^\star = (1, 0, 0): three bounds are active (z_1 \le 1, z_2 \ge 0, z_3 \ge 0) plus the equality, four constraints for three variables, so the multipliers are not unique.   3. Build it yourself. Write a twenty-line interior-point solver for problems with inequalities only, following Parts 3 to 5 without the polish, and compare its answer on the N = 8 MPC QP of the numbers script with the package's.

    Hint

    You need rd, rp, rc, the matrix H + G^\top D G, the two elimination formulas and the step rule. Twelve iterations suffice at \sigma = 0.1.

    Solution 
    def ipm(H, f, G, g, sigma=0.1, tol=1e-9, iters=100):
    n, m = len(f), len(g); z = np.zeros(n); s = np.maximum(g - G @ z, 1.0); lam = np.ones(m)
    for _ in range(iters):
        rd = H @ z + f + G.T @ lam; rp = G @ z + s - g; mu = s @ lam / m; rc = sigma * mu - s * lam
        if max(abs(rd).max(), abs(rp).max()) < tol and mu < tol: break
        D = lam / s; t = (rc + lam * rp) / s
        dz = np.linalg.solve(H + G.T @ (D[:, None] * G), -rd - G.T @ t)
        ds = -rp - G @ dz; dl = (rc - lam * ds) / s
        a = min([1.0] + [-0.99 * s[i] / ds[i] for i in range(m) if ds[i] < 0] + [-0.99 * lam[i] / dl[i] for i in range(m) if dl[i] < 0])
        z, s, lam = z + a * dz, s + a * ds, lam + a * dl
    return z, lam
# the N = 8 problem of the numbers script, with the bounds stacked as rows
from advanced_mpc_lmpc.qp import stack_inequalities
kw = mpc_qp(8, np.array([-3.0, 0.0]))                 # from a04_numbers.py
G, g = stack_inequalities(8, kw["A_ub"], kw["b_ub"], kw["lb"], kw["ub"])
z, lam = ipm(kw["H"], kw["f"], G, g)
print(np.abs(z - solve_qp(**kw).x).max())             # about 1e-10: the polish accounts for the difference

    Without the polish the answer agrees with the package's to about 10^{-10}, the tolerance; with it, to round-off.

  4. Centring. Run the N = 8 MPC QP with \sigma = 0.01, 0.1, 0.5, 0.9 and tabulate the iteration counts. Explain the trend, and why production solvers do not simply use the smallest \sigma.

    Hint

    solve_qp(..., sigma=...); think about what happens to the weights \lambda_i / s_i when the iterate is far from the central path.

    Solution

    12, 13, 34 and over 100 iterations. A small \sigma aims straight at the solution and converges in the fewest steps here, but on harder problems an iterate that leaves the central path acquires badly scaled weights, the reduced system becomes ill conditioned and the steps are cut to almost nothing by the boundary rule. Adaptive rules such as Mehrotra's predictor-corrector take an aggressive step when it is safe and a centring step when it is not; the course's constant \sigma = 0.1 is a safe middle on every problem it meets.

  5. Certify infeasibility. For the cart with N = 3 from (3, 2), call solve_qp and feasibility_margin on the same constraints. Interpret the margin, and find the first horizon from which (3, 2) becomes feasible, if any.

    Hint

    Solution

    The solver fails and the margin is 1/3: the first predicted position is at least 4.5 whatever u \in [-1, 1], half a unit outside the box, and the uniform relaxation that repairs it is 0.5 on the position row, 1/3 after the row's scaling by the stacked matrices. Part 12

The chapter on one page

  1. The method: Newton's method on the KKT system with s_i \lambda_i = \sigma \mu instead of 0, iterates kept strictly inside, \mu driven to zero.
  2. Stacking: bounds become inequality rows; one matrix G, one slack vector s; the start is z = 0, s = \max(g - Gz, 1), \lambda = 1.
  3. Residuals: rd, rp, re are the linear KKT conditions, rc the centred complementarity; they vanish after one full step on a QP except rc.
  4. The reduced system: (H + G^\top D G) with D = \lambda / s, size n + p; the weights switch constraints on and off continuously.
  5. The step: at most 99% of the way to the boundary; stop when residuals and \mu are below 10^{-9}; one Newton step per decade.
  6. The polish: solve the equality-constrained QP on the detected active set, accept if KKT-exact; residuals go from 10^{-10} to 0.
  7. Against SLSQP: same answers to the SQP's tolerance, 13 iterations at N = 8 and N = 20, about a millisecond; both fail on infeasible problems.
  8. Certificate: feasibility_margin, an LP in a different code base, returns 0 for feasible constraints and the smallest repairing relaxation otherwise.

The vocabulary, in one table

Word Meaning
Slack s g - Gz, kept strictly positive during the iteration.
Complementarity \mu The average of s_i \lambda_i; zero at the solution.
Centring parameter \sigma The fraction of \mu aimed at in the next step.
Central path The curve of solutions of the perturbed system as \mu \to 0.
Reduced Newton system The (n + p)-square system left after eliminating \Delta s and \Delta \lambda.
Fraction to the boundary The step rule that keeps s and \lambda positive.
Active-set polish An exact solve on the detected active set, accepted if KKT-exact.
Feasibility margin The smallest uniform relaxation making the constraints compatible; zero if feasible.
SLSQP SciPy's sequential quadratic programming method, the package's previous solver.

Scope. A dense primal-dual interior-point method with a constant centring parameter for small convex QPs, as implemented in the course package and its browser toolkit. Mehrotra's predictor-corrector, sparse factorisations, first-order methods and active-set methods with warm starts are named, not implemented; nonlinear programs are chapter A5.
